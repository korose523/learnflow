# R11 实证结果（可粘贴进 M3 §5.4）

## 可直接粘贴的中文段落

在 LearnFlow 自有数据上，我们对 R11（Razavi & Powers 2026, IJAIED，以 LLM+树模型达到 r=.87）所代表的「结构化特征工程 → 树集成」路径做了实证检验，目标是回答：该路径能否比本稿当前的 LLM 直接/排序评级更好地预测题目难度。我们在 DBE-KT22（E1A，n=212，专家难度 1–3 为金标准）与 XES3G5M（E2X，n=120，以作答对数胜率派生的实证四分位为金标准）上，分别逐题构造结构化特征——词法长度/词数/可读性、是否含图或 LaTeX、选项数与正确选项数、关联知识点数（DBE），以及轻量文本特征（长度、数学符号密度、选项数）加 LLM 抽取评级（XES）——并以 5 折交叉验证的袋外预测报告 Spearman ρ 与回归 RMSE（bootstrap 95% CI，seed=42）。

结果显示，两数据集结论分化：**DBE 上**，结构化特征 + 随机森林将 ρ 从 LLM 直接评级基线的 0.2195（CI [0.086, 0.345]）提升至 0.562（CI [0.446, 0.662]，p≈4.5e-19），梯度提升亦达 0.489；两置信区间不重叠，增益显著且幅度很大，证明 R11 的「特征工程 → 树模型」路径在 LearnFlow 数据上确实可行。**XES 上**，基线 LLM 直接评级 ρ=−0.038（不显著，CI 跨零），而结构化特征 + 树模型仅给出 ρ≈0.18–0.20（RF+LLM: 0.200，CI [0.026, 0.369]），增益为正但幅度有限且仅弱显著——这主要源于 XES 目标为作答派生的实证四分位（噪声代理），且本实验仅采用轻量文本特征、未做深入内容建模。

需要诚实指出：本实验**并未、也不声称复现** R11 的 r=.87——二者数据分布、特征粒度与标注协议均不同，本稿仅证明「在 LearnFlow 自有数据上，结构化特征是否把 ρ 提升到高于直接评级基线」这一更窄的问题。综合而言，R11 路径在 DBE 上是明确可行的增益路径，但本稿的研究目标是为单模型先验可靠性设定边界（见 §5.4 主线），而非追求预测力的上限。因此我们将 R11 列为**增益路径 / 未来工作**：在 M3 主消融与可靠性边界之外，它提供了可叠加的、可解释的改进方向，而非对现有 LLM 直接评级基线的替换。

## Verdict 建议（一行）

**verdict: KEEP-AS-GAIN-PATH** —— R11「特征工程→树集成」在 DBE 上获显著增益（ρ 0.22→0.56），列为 §5.4 的可行增益路径/未来工作，不替换当前 LLM 直接评级基线；XES 上增益弱且待深化，作为受限证据标注。
