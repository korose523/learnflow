## 1. 模拟器设计（Learner–Item 交互）

**状态**：真实掌握度 $m_t\in[0,1]$（隐藏），$m_0\sim U(0.05,0.15)$。

**动作（有序）**：难度 $d\in\{0,\dots,9\}$，潜难度 $\delta_d=\mathrm{linspace}(-2,2,10)$ **单调递增**——即"有序动作序贯决策"。

**成功概率（Rasch / 1PL 型）**：
$$p_{\text{succ}}(m,d)=\sigma\!\big(\alpha\,(4m-2-\delta_d)\big),\qquad \alpha=1.5 .$$

**学习增益（合意难度核，desirable difficulty）**：
$$g(m,d)=\eta\,\exp\!\Big(-\tfrac{(p_{\text{succ}}-p^\*)^2}{2\sigma_g^2}\Big)\cdot\mathrm{LogNormal}(0,s),\quad
\eta=0.06,\;p^\*=0.75,\;\sigma_g=0.18,\;s=0.20 .$$

**遗忘（BKT 式衰减）**：$m_{t+1}=\mathrm{clip}\big(m_t+g-\lambda m_t,\;0,\;1\big),\;\lambda=0.015$。

**代价（单位时间/认知负荷）**：$c_d=c_0+c_1(\delta_d-\delta_0),\quad c_0=1.0,\;c_1=0.5$（越难代价越高）。

**观测**：智能体仅见 $\hat m_t=\mathrm{clip}(m_t+\mathcal N(0,0.05),0,1)$（含噪掌握度估计）、动作 $d_t$、实现增益 $g_t$。

**参数取值来源**：**全部为"合理设定"，非拟合真实数据**。依据教学系统常识取量级（成功率阈值 $p^\*\approx0.75$ 对应"合意难度"文献区间的中值；单轮增益 $\eta=0.06$ 使 120 轮内掌握度可由 ~0.1 升至 1；遗忘率 $\lambda=0.015$ 为弱遗忘）。**明说：若换成其他合理取值，绝对数值会变，但策略排序与心流边界定性结论见 §6 的稳健性讨论。**

**轮次**：$T=120$；**种子**：$SEEDS=60$。

## 2. 策略（奖励按 $\eta$ 归一化到 $\sim[0,1]$，使 UCB bonus 尺度匹配）

| 层 | 策略 | 说明 |
|---|---|---|
| T1 无上下文 | **ε-greedy**（ε=0.1） | 忽略次序与状态 |
| T1 无上下文 | **Thompson Sampling** | Normal-Normal（σ=0.15）逐臂后验采样 |
| T1 有次序 | **Lipschitz-UCB** | $U_j=\min_k[\bar x_k+L\lvert j-k\rvert+\sqrt{2\ln(t+1)/n_k}]$，$L=0.10$ |
| T2 有上下文 | **Contextual-UCB** | 对 $\hat m$ 分 10 箱，箱内 UCB |
| T3 LLM 先验 | **Ctx+LLM先验（正确）** | 先验形状=真实期望增益（$\lambda_0=4$ 伪计数） |
| T3 LLM 先验 | **Ctx+LLM先验（错误,偏难）** | 先验把学习者当更超前（+0.18 掌握度）→偏好更难 |
| 参照 | **matched（模型已知,用 $\hat m$）** | 参数已知、状态含噪的匹配难度策略 |
| 参照 | **Oracle** | 已知真实 $m_t$，取 $\arg\max_d\mathbb E[g]$ |

**指标**：期末累积增益、**伪遗憾** $\sum_t\big(\max_d\mathbb E[g(m_t,d)]-g_t\big)$、平均错误率、达目标掌握度（$m\ge0.90$）轮次（右删失于 $T{+}1$）、达标率。

## 4. "LLM 先验边界"的定量刻画

- **正确先验收益**：相对无先验 Contextual-UCB，期末增益 **+0.273**（$d_z=+2.13$，$p<10^{-22}$），达标轮次 **27.0→18.4（提前 32%）**。
- **错误先验代价**：偏难先验反而 **−0.449**（$d_z=-3.42$），达标轮次 **27.0→33.9（推迟 25%）**，甚至低于无次序的 Lipschitz-UCB（4.55 vs 4.94）。
- **边界**：LLM 先验的价值**符号取决于正确性**——正确则加速、错误则劣于无先验。收益上界（matched，7.09）与 oracle（7.18）给出可达天花板；即使正确先验（5.27）也仅达天花板的 ~73%，说明**先验只能部分替代对学习者状态的精确建模**。

## 5. 可直接写入 M3 的结果素材

1. **有序动作 + 上下文显著优于无次序/无上下文**：Contextual-UCB 4.996 > Lipschitz-UCB 4.942 > Thompson 3.511 > ε-greedy 3.229（同种子配对均显著，$p<10^{-11}$）。
2. **LLM 先验的边界效应**：正确先验期末增益 5.270、达标 18.4 轮（最优学习型策略）；错误先验 4.547、33.9 轮（最差）。**先验价值可正可负**，$d_z$ 分别 +2.13 / −3.42。
3. **心流区非退化**：错误率–学习代价非支配边界斜率 $-0.0097$（95%CI $[-0.013,-0.008]$，$P(\text{斜率}\ge0)=0$），10 个边界点，代价跨度 19；**代价须用"达目标轮次"而非"单题时间"**方能显现负斜率。
4. **天花板参照**：模型已知的 matched 策略 7.090 / 16.7 轮，逼近 oracle 7.177 / 16.0 轮——为"若状态估计与模型均精确可达的性能上界"。
