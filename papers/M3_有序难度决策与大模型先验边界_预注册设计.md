## 摘要

自适应学习的两项核心决策——"下一题给什么难度"与"难度先验从何而来"——各自依赖一个未经检验的前提。前者默认不同难度档的期望增益互不相关；后者默认大语言模型（LLM）的离线难度标注可作为可靠的在线决策先验。本文提出一项预注册研究设计，在同一分析语汇下并置两个可独立成立的子设计。子设计一把难度选择形式化为"动作有序、奖励为学习增益、状态含记忆可提取性"的序贯决策问题：给出有序动作的遗憾界适配（Lipschitz 连续性前提及其数据估计与独立检验）、心流通道的二维可标定形式化（以非支配边界 ∂Φ⁺ 取代固定正确率区间 [0.75, 0.85]），并把可提取性 R_k(t) 接入动作价值 Q(s, d)——即把记忆科学从"预测"转为"决策"；其评估以自建自验的学习者模拟器为对象，模拟器验证为不可省略的前置门槛。子设计二把 LLM 难度标注的研究问题从标注层的相关性推进到决策层的损失：以集成规模 n_ens 为唯一自变量定义机器共识阈值 δ，以累积学习增益损失 Δ(δ) 定位最优集成规模 n\* 与判据 δ\*，并给出压过有偏先验所需的最少在线作答数 N\*；中文 K12 题库作为未被覆盖的格子构成本子设计的场景增量。全文结论以方法论与判据形式表述，而非绑定于某一具体模型或某一具体遗憾界的数值。

**关键词**：有序动作空间；Lipschitz bandit；心流通道；可提取性；序贯决策；大语言模型难度标注；机器共识；预注册

## Abstract

Two core decisions in adaptive learning — "what difficulty to present next" and "where the difficulty prior comes from" — each rest on an untested premise. The former assumes expected gains across difficulty levels are mutually uncorrelated; the latter assumes that offline LLM difficulty annotations provide a reliable prior for online decisions. We present a preregistered research design that places two independently valid sub-designs under one analytical vocabulary. Sub-design 1 formalises difficulty selection as a sequential decision problem with **ordinal** actions, learning gain as reward, and **memory retrievability** in the state: it adapts regret bounds to ordinal action spaces (with a Lipschitz premise that is estimated and separately tested), upgrades the flow channel from a fixed accuracy interval [0.75, 0.85] to a two-dimensional calibratable region characterised by its non-dominated boundary ∂Φ⁺, and makes retrievability R_k(t) a component of the action value Q(s, d) — the step from using memory science for *prediction* to using it for *decision*. Its evaluation targets a self-built, self-validated learner simulator, and simulator validation is a non-negotiable gate. Sub-design 2 moves LLM difficulty annotation from the annotation layer to the decision layer: using ensemble size n_ens as the single independent variable, it defines a machine-consensus threshold δ, locates the optimal ensemble size n\* and the criterion δ\* via the cumulative-learning-gain loss Δ(δ), and estimates N\*, the minimum number of online responses needed to override a biased prior; a Chinese K12 item bank, a cell uncovered by existing work, is the differentiating scenario. All conclusions are framed as methodology and criteria rather than tied to any specific model or regret bound. Results are not yet produced; the design will be preregistered before any data contact.

**Keywords**: ordinal action space; Lipschitz bandits; flow channel; retrievability; sequential decision making; LLM difficulty annotation; machine consensus; preregistration

## 1 引言

### 1.1 两个被跳过的前提

"下一题给学生什么难度"是自适应学习系统的核心决策。工程上最常见的实现是贪心加精确等值匹配：把题目标签难度与目标难度做精确相等匹配，取第一条满足条件的题目。这一实现在效率上可行，却隐含一个很强的建模假设——**不同难度档的期望学习增益互不相关**，因此可以把每一档当作独立的"臂"。本文指出该假设在两个可证伪的结构性质上失效。其一，难度是**有序**的：相邻难度的题目在内容、所需技能与认知负荷上连续，相邻档的期望增益应当满足 Lipschitz 连续性，而非彼此独立。其二，学习者的记忆状态是**动态**的：同一道题在"刚学过"与"两周没碰"两种状态下，对同一学生的有效难度判然不同；把难度视为题目的静态属性，等于丢弃了这一信息。

与此同时，难度的**先验从何而来**是另一个被跳过的前提。传统做法依赖专家打分或真实作答后的项目反应理论（IRT）标定，成本高、周期长。大语言模型（LLM）提供了一个诱人的替代：用 LLM 离线标注难度，再作为在线自适应决策的先验。这一路线在工程上极具吸引力，却在学术上建立在一个**尚无共识**的前提之上——当前文献分成尖锐对立的两派（见 1.3 与 2.5）。两派都止步于**标注层**，回答的是"LLM 标注与人类标注的相关性有多高"；没有人回答下游工程真正关心的问题：**这个偏差在自适应决策上造成多大损失、什么条件下这个先验会损害而非改善决策。**

本文提出一项预注册研究设计，把这两个被跳过的前提分别正面处理。

### 1.2 两个子设计及其关系

本文由两个原本可独立成文的子设计构成，合并的理由不是篇幅，而是它们共享同一套分析语汇与同一类研究对象（"难度"这一量在决策中的位置）。

**子设计一（序贯决策）** 把难度选择形式化为"动作空间有序、奖励为学习增益、状态含记忆衰减"的 MDP。它的核心陈述是：难度选择满足有序动作空间理论的适用前提，且记忆可提取性应当作为状态分量进入动作价值——这是把记忆科学从预测接入决策的关键一步。

**子设计二（先验审计）** 把 LLM 难度标注的问题从标注层移到决策层：以集成规模为唯一自变量定义机器共识阈值 δ，以决策层损失 Δ(δ) 反推判据 δ\*，并给出压过有偏先验所需的最少在线作答数 N\*。

二者**互不以前者的结果为前提**。子设计一的实验对象是自建自验的模拟器，其参数由本文在留出日志上自行估计，不消费他篇产出；子设计二的真值来自真实学习者响应标定的 IRT 难度，与子设计一的重叠仅在于两者都使用"难度"这一概念，而非任一具体数值。这一独立性的工程意义是明确的：任一子设计的延期不会导致另一子设计无法成立。

### 1.3 文献进展与本文定位

本文的定位必须建立在诚实的文献判断上。把"难度/课程选择当作 bandit"已不新颖：Castleman、Macar 与 Salleb-Aouissi（2024, RLC）已构建**分层 MAB 智能导师**（概念 MAB + 题目 MAB + BKT + 遗忘衰减 MCM），在 ASSISTments 上模拟 1 500 名学生，难度感知版显著优于难度无关版与随机版，且**已开源**——这是本篇必须新增的核心 baseline；Chen 等（2025，待核验）把课程选择建模为**非平稳 MAB**。Lipschitz bandit 出现三条重要新分支：**对抗式自适应离散化**（Podimata & Slivkins, 2025）、**非平稳 Lipschitz bandit**（Nguyen、Gaucher 与 Vernade, ICLR 2025）、**字典序 Lipschitz bandit**（Xue 等, JMLR 26, 2025）。记忆状态建模在知识追踪侧已成标配但**尚未进入决策层**：MemoryKT（Lin 等, 2025）、MLEKT（Qian 等, 2025）、SAFFKT（Song 等, 2024）、TPR-KT（Zhang 等, 2025）把遗忘用于**预测**。**本文因此把子设计一的护城河明确收窄到一句话：把可提取性（extractability）作为 MDP 状态，用于决策而非预测。** 其余部分（有序动作、遗憾界适配）是已有理论的适配，本文不宣称新证明。

在 LLM 难度标注一侧，**乐观派**以 Ballon、Algaba、Verbeken 与 Ginis（2025, LLMcompare）为代表：以 LLM 成对比较 + Bradley-Terry 模型估计难度排序，与人类标注的 Pearson r ≥ 0.80（n = 1876），注入 10% 噪声后相关系数衰减小于 6%。**悲观派**以 Li、Chen、Xiao、Chen、Jiao 与 Zhou（2025）为代表：在 20 余个模型 × 4 个领域（USMLE / Cambridge / SAT-R / SAT-M）上，与人类难度的平均 Spearman ρ < 0.5，USMLE 上的"Savant Rate"达 70.4%，模型自评 AUROC ≈ 0.55（接近随机），且**模型规模越大反而越不对齐**——模型收敛于一种"机器共识"，而非人类难度。值得指出，乐观派的评价场景是"合成数据生成的难度排序"，悲观派的真值来自 field testing（真实响应），二者**测量的对象并不完全相同**。本文的子设计二不在这两派之间选边，而是换一个提问位置：不问标注相关性有多高，而问这个偏差到了下游会花掉多少学习增益。

### 1.4 本文贡献

**子设计一。**

**C1 — 有序动作空间的形式化与遗憾界适配。** 论证难度档的期望增益满足 Lipschitz 连续性，据此以连续臂 / Lipschitz bandit 替代独立动作 UCB / Thompson Sampling，把遗憾界由 Õ(√(K·T)) 适配到 Õ(T^{(d̄+1)/(d̄+2)})（一维约 Õ(T^{2/3})），并给出 Lipschitz 常数 L 的从数据估计方法与**不依赖同一量的独立检验**（避免"以同一量既估计又检验"的循环）。本文进一步补入非平稳与对抗式两条设定。这是已有理论的适配，价值在于证明难度选择满足该理论前提。

**C2 — 心流通道的二维可标定形式化。** 把心流通道从一维正确率区间升级为二维区域：维度一为事前错误率（能力—难度匹配），维度二为努力/时间代价（反应时 z 分数、提示使用次数、放弃率）。心流区是这两个不等式交集构成的**可行区域** Φ，其理论含义落在 Φ 的非支配边界 ∂Φ⁺ 上；工程常用的固定区间 [0.75, 0.85] 只是 ∂Φ⁺ 在忽略代价维度时的投影。可证伪命题 F：∂Φ⁺ 非退化，即在（错误率, 代价）平面上呈负斜率。

**C3 — 遗忘作为状态转移：把可提取性接入决策（子设计一核心）。** 定义状态 s = (θ, {R_k(t)}_k)，其中 R_k(t) 为知识点 k 在时刻 t 的可提取性；动作价值为 Q(s, d)，策略为 π(s)。给出在可提取性单调衰减下的结构性预测（最优难度的单调漂移、复习与推进的切换点）与可检验含义，并明确其与"预测"路线的差异。

**子设计二。**

**D1 — 机器共识陷阱的可操作阈值 δ（以集成规模为唯一自变量）。** 悲观派观察到模型收敛于机器共识，但未给出可操作判据。本文把这一现象升级为阈值：定义 **δ = ρ_ens(human) − ρ_pair(human)**，其中 ρ_pair(human) 为"以单个模型为单位的平均对齐度"，ρ_ens(human) 为"以集成（把 n 个模型的排序聚合为一个排序）为单位对人类的对齐度"。这样定义是为了解决可比性问题：若一边取模型两两相关、另一边取模型与人类相关，两者的平均对象数不同（模型对数 vs 模型数），相减得到的量纲不干净且会随模型数变化。改用"单模型 vs 集成"这一同基准比较后，δ 的含义变得明确——**δ > 0 表示把模型聚在一起只让它们更接近彼此、并未更接近人类**。判据：当 δ > δ\* 时，应把集成规模限制在 n\* 以内或直接禁用集成。

**D2 — 决策层损失 Δ(δ) 与判据 δ\* 的计算流程（本文核心抓手）。** 把 LLM 先验接入标准序贯选择框架作离策略/模拟器评估，量化"先验偏差 δ ⇒ 累积学习增益损失 Δ(δ)"，并给出"何时该用 / 不该用 LLM 先验"的可操作阈值。以**集成规模 n_ens 为唯一自变量**，δ\* = δ(n\*)，其中 n\* 是决策层损失曲线的极小点——判据因此不是拍定的阈值，而是由损失曲线反推的值。

**D3 — 层级贝叶斯校准与 N\* 的估计。** 提出"LLM 先验 → IRT 后验"的层级校准模型，回答问题：**需要多少条真实在线作答，才能把有偏的 LLM 先验纠正到可用精度？**给出 N\* 的估计与置信区间，并报告其相对先验偏差 δ 与题目区分度的依赖关系。

## 2 相关工作

### 2.1 教育场景中的 bandit 与 RL 选题

Castleman 等（2024）的分层 MAB 智能导师是其中最具代表性的实现：上层 MAB 选概念、下层 MAB 选题目难度，配以 BKT 掌握度估计与 MCM 遗忘衰减，在 ASSISTments 模拟环境（1 500 名学生）中，难度感知版取得最优掌握度（约 0.92）。该工作的开源使其成为子设计一不可省略的 baseline。本文与上述工作的差异在两个结构性质上：**有序性**（相邻难度档信息可借用）与**记忆状态**（可提取性进入状态）。

### 2.2 Lipschitz bandit 的三条新分支

Lipschitz bandit 假设期望奖励函数在动作空间上满足 Lipschitz 连续。近期三条分支与本文直接相关：对抗式自适应离散化（Podimata & Slivkins, 2025）给出首个对抗奖励下的 Zooming 算法与实例相关遗憾界；非平稳设定（Nguyen 等, 2025, ICLR）给出动态遗憾 Õ(L̃^{1/3}T^{2/3})；字典序多目标（Xue 等, 2025, JMLR 26）给出按重要度分层的遗憾界与下界。前两条用于本文主设定；第三条服务于姊妹方向的合规优先级问题，本文不展开。

### 2.3 记忆状态建模：从预测到决策

MemoryKT、MLEKT、SAFFKT、TPR-KT 等已经把遗忘与记忆状态用于提升知识追踪的预测精度，但**尚未进入动作选择层**。这构成一个结构性的空白：既然"同一个学生在同一道题上的有效难度随可提取性变化"，那么最优难度选择必然依赖于可提取性——而预测模型只输出"下一题答对的概率"，不输出"现在应该选什么难度的题"。

### 2.4 心流与最优挑战

心流理论主张最优体验位于"挑战—技能平衡"处，工程实现常把该平衡量化为固定的正确率区间（如 [0.75, 0.85]）。Rosas、Padilla-Zea 与 Burgos（2026, Sensors）以生理信号 + 非线性分析验证平衡公理，同时**暴露心流理论内部存在既有矛盾**；Dell'Anna 等（2025, LUMAT-B MAVI 31；待核验）指出基于先验难度的推荐可能无法维持最优体验，需按心流动态调整。本文据此把心流区从固定区间改为以其非支配边界刻画的二维区域。

### 2.5 LLM 难度标注的两派及其中间立场

**乐观派**（Ballon 等, 2025）以 LLM 成对比较 + Bradley-Terry 聚合，在**无 ground truth** 条件下估计难度，其 r ≥ 0.80 与对噪声的稳健性构成主要证据；需注意其评价场景是"合成数据生成的难度排序"。**悲观派**（Li 等, 2025）的核心发现有三：跨领域平均 Spearman ρ < 0.5；模型自评与真实表现间 AUROC ≈ 0.55，说明模型对自身"会与不会"缺乏校准；**模型规模越大越不对齐**，收敛于"机器共识"——第三点直接否定了"用多模型投票提高置信度"这一常见工程做法。**中间派**（Liu、Bhandari 与 Pardos, 2025, BJET）把 6 个 LLM 当作合成被试，报告 GPT-3.5 与人类难度排序 ρ = 0.87，并可通过混合重采样把仅 50 名人类样本下的 ρ 从 0.89 提升到 0.93，但同时发现"**窄分布陷阱**"——合成被试的能力分布过窄，会系统性低估区分度。

此外，Easy2Hard-Bench（Ding 等, 2024）以集体 LLM 表现作难度代理，发现 **IRT 结果比 GPT-4 自身排序更贴合人类偏好**，由此形成本文的关键张力点：乐观派主张"集成更好"，悲观派主张"集体收敛于机器共识"——子设计二的 δ 判据正是为消解这一张力而设。Pratiwi 与 Fakhrurroja（2025）以 Gemini 2.5 Pro 标注 505 道题的 Bloom 层级，报告与人工验证一致率 88%、模型间一致 94%，但作者自承单验证者、未做评分者信度（IRR）；Parfenova 等（2025，待核验）发现 LLM 更接近编码金标准却被人类评分更低。这些工作共同提示：**模型间一致率高并不等于模型—人类一致率高**——这正是 δ 的直觉。

### 2.6 有序动作空间在教育与推荐中的先例与缺口

把动作空间视为有序而非无序，在教育以外已有先例：对抗式 Lipschitz bandit 被用于动态定价与拍卖保留价设定（Podimata & Slivkins, 2025），其动作（价格）天然有序且相邻价格的期望收益满足平滑性——这说明"有序动作 + 平滑奖励"是被广泛接受的建模选择。教育领域的特殊性在于两点：奖励不是即时收益，而是**延迟且不可直接观测的学习增益**，须由剂量—反应关系与记忆模型间接刻画；动作效果依赖学习者的**记忆状态**，而该状态在会话之间持续演化。困难不在动作空间，而在奖励与状态的可得性。

## 3 问题形式化

### 3.1 序贯决策的要素

定义难度选择为一个 MDP：**状态** s_t = (θ_t, {R_k(t)}_k, e_t)，其中 θ_t 为能力估计，R_k(t) 为知识点 k 的可提取性，e_t 为近期努力/时间代价特征；**动作** d_t ∈ D ⊆ ℝ（难度档），D 为**有序**离散或连续集合；**奖励** r_t = 学习增益（如掌握度增量或下一窗口的事后正确率增益），**而非**本次答对与否；**转移**：能力按学习增益更新，可提取性按记忆模型随时间为单调衰减、随成功复习上升。

### 3.2 有序动作空间与遗憾界适配（C1）

**前提 L（Lipschitz 连续性）**：存在 L > 0 使 |μ(d) − μ(d′)| ≤ L|d − d′| 对一切 d, d′ ∈ D 成立，其中 μ(·) 为期望学习增益函数。在前提 L 下，连续臂 bandit（Zooming 算法与 HOO）的遗憾界为 Õ(T^{(d̄+1)/(d̄+2)})，其中 d̄ 为有效维度；一维情形约 Õ(T^{2/3})，优于独立动作 UCB 的 Õ(√(K·T))（当 K 足够大时）。

**L 的估计与检验的分离（避免循环）。** 以相邻难度档在共享题目集上的平均增益差作 L 的矩估计，或以上下文回归的正则化路径估计，并给出置信区间。需要指出，用同一量既估计 L 又检验前提 L 会构成循环，因此本文的检验刻意不依赖同一量：**L 由相邻档增益差的截面回归估计，而前提 L 的检验改用"增益差随档距的次可加性"与"跨会话外推误差"两条独立证据**（详见第 5.1 节）。**C1 的定位（不作过度声明）**：C1 不产生新的遗憾界，其贡献是证明难度选择满足该理论的适用前提，并给出 L 的可估计算法。

**非平稳与对抗扩展。** 学习者能力在会话内漂移使奖励分布非平稳，这在真实日志中是常态而非例外。本文主设定采用 Nguyen 等（2025）的非平稳 Lipschitz bandit，得到动态遗憾 Õ(L̃^{1/3}T^{2/3})，其中 L̃ 同时吸收函数平滑度与漂移速率；稳健性设定采用 Podimata & Slivkins（2025）的对抗式 Zooming，用于覆盖奖励含对抗性成分（猜测、注意力波动、故意作错）的情形。

### 3.3 心流通道的二维可标定形式化（C2）

定义可行集为

  Φ = { (d, e) : ΔGain(d) ≥ g₀ 且 Cost(e) ≤ c₀ }，

其中 ΔGain(d) 为先验错误率方向的期望增益，Cost(e) 为努力/时间代价（由反应时 z 分数、提示使用次数、放弃率的合成刻画）。Φ 是一个由两个不等式交集构成的**区域**，而不是一条曲线。真正具有理论含义的是该区域的**非支配集合**

  ∂Φ⁺ = { (d, e) ∈ Φ : ¬∃(d′, e′) ∈ Φ 使 ΔGain(d′) ≥ ΔGain(d) 且 Cost(e′) ≤ Cost(e)，二者至少一严格 }。

**边界标定**：错误率方向的 g₀ 由本文自估的剂量—反应关系给出，时间方向的 c₀ 由反应时分布的高分位确定。**可证伪命题 F**：∂Φ⁺ 非退化，即在 (错误率, 代价) 平面上呈负斜率——存在真实的增益—代价权衡，提高增益必然以更高的努力代价换取；工程上常用的固定区间 [0.75, 0.85] 只是 ∂Φ⁺ 在"代价维度被忽略"时的一个投影。命题 F 与 Φ 的定义不冲突：Φ 是允许集，∂Φ⁺ 是其上的非支配前沿，二者描述同一集合的不同部分。

### 3.4 可提取性作为 MDP 状态（C3，子设计一核心）

把 R_k(t) 作为状态分量。同一道题 j 在知识点 k 上的**有效难度**为 β_eff(j, t) = β_j − λ·R_k(t)，λ ≥ 0（示意形式），即高可提取性等价于有效难度下降。动作价值函数 Q(s, d) 因此显式依赖于 {R_k(t)}。给出两条结构性预测。

**命题 M1（最优难度的单调漂移）.** 设动作 d 表示被选题目的**内在难度** β_j，且 μ(·) 为单峰。在 R_k(t) 单调衰减的条件下，最优动作 d\*(s) 随 R_k(t) 下降而**单调下降**：遗忘越多，同一道题的有效难度 β_eff = β_j − λR_k(t) 越高，为把有效难度维持在 μ(·) 的峰值附近，系统必须改选内在难度更低（即更容易）的题目。这一方向可被数据直接反驳——若观测到相反方向的漂移，则要么 λ ≤ 0，要么 μ(·) 非单峰。

**命题 M2（复习与推进的切换）.** 当 R_k(t) 高于某阈值时，插入该知识点复习题的边际价值低于呈现新知识点；R_k(t) 低于该阈值时结论相反。这给出"何时复习、何时推进"的可检验决策规则，其阈值可由 Q(s, d) 对不同知识点的边际差直接定位。

**与预测路线的差异（关键一句）.** MemoryKT / MLEKT / SAFFKT 把遗忘用于**预测**下一题答对的概率；本文把可提取性用于**决策**——计算动作价值 Q(s, d) 并据此选择难度。

### 3.5 LLM 先验可靠性审计的形式化（子设计二）

**真值与口径澄清。** 记题目 j 的 IRT 难度为 βⱼ（真值），模型 m 对题目 j 的标注难度为 b̂_mj。Li 等（2025）的"人类难度"来自 field testing（真实响应），其口径可能基于经典测验理论的 p 值或分位排序，与本文的 logistic 潜变量口径不完全一致。本文须显式说明两者差异，并在共同题目子集上作一致性检验（例如将 p 值与 θ − β 作秩相关），以此界定"真值"的可比性边界。对齐度量取 Pearson r、Spearman ρ、二次加权 Kappa（QWK）与系统偏移方向，并按学科 × 题型 × 难度分位 × 模型规模 × 提示策略五维分解，形成"哪些格子可用"的边界地图。

**信任阈值 δ。** 定义 δ = ρ_ens(human) − ρ_pair(human)，含义见 1.4 的 D1。**判据**：当 δ > δ\* 时，多模型集成的边际收益为负，应把集成规模限制在 n\* 以内或禁用集成；δ\* 由决策层损失曲线确定（流程见下）。

**决策层损失 Δ(δ)。** 把 LLM 先验接入序贯决策框架：状态含学习者能力与记忆可提取性，动作是从题库选择下一题，奖励为学习增益。需要说明，本文**不提出新的选择策略**——框架采用两种标准且公开可复现的基线（ε-greedy 与 Thompson Sampling），目的只是度量先验偏差的后果。以带偏差 δ 的先验 π_δ 替换无偏先验，作离线/模拟器评估，得到累积学习增益 G(π_δ)，定义 Δ(δ) = G(π_0) − G(π_δ)，输出敏感度曲线并给出"先验偏差在何种量级时使用该先验不如直接冷启动"的交叉点。

**判据 δ\* 的计算流程与终止准则。** 关键在于把"谁是自变量"说清楚——本文以**集成规模 n_ens 为唯一自变量**，δ 是它的函数，δ\* 是该函数在最优规模处的取值。流程分四步：对 n_ens ∈ {1, 2, 4, 8, …} 分别构造集成排序（取模型排序的平均位次或 Bradley-Terry 聚合），计算 δ(n_ens) = ρ_ens(human) − ρ_pair(human)；把每个集成排序作为先验接入决策层（见本节上段），得到 Δ(n_ens) = G(π_0) − G(n_ens)；在 n_ens 上定位 Δ 的极小点 n\*（若 Δ 随集成规模先降后升，则 n\* 是损失最小的集成规模）；定义 δ\* = δ(n\*)，把判据落地为一条可执行规则——**当实测 δ 超过 δ\* 时，把集成规模限制在 n\* 以内或直接禁用集成**。这样，δ\* 不是拍定的阈值，而是由决策层损失曲线的极小点反推出的值。该流程须与显著性检验排序：先检验 δ(n_ens) 在各格子上是否显著为正（若全不显著，则机器共识陷阱在该任务上不成立，流程终止）；仅在显著为正的格子上才继续计算 n\* 与 δ\*。

本文设定**三条终止准则**以保证研究在结果不利时能诚实收束：其一，若 δ 在全部模型与全部格子上均不显著为正，则"机器共识陷阱"在该任务上不成立，应报告为阴性发现而非强行解释；其二，若 Δ(δ) 在考察的偏差范围内始终接近于零，则"决策层损失"这一抓手失效，本文应退回标注层研究并降档投稿；其三，若整体结论为纯正面（相关性尚可、无任何负面条件），按第 5.6 节的终止条件主动终止。三条准则在预注册中写明，避免事后择优。

**层级贝叶斯校准与 N\*。** 以 LLM 先验为层级模型的先验均值、以真实在线作答为似然，构造"LLM 先验 → IRT 后验"的校准模型，求最小的 N\* 使后验难度估计的期望误差低于阈值，并报告 N\* 对先验偏差 δ 与题目区分度的依赖关系。

## 4 实验设计

### 4.1 数据与模拟器（子设计一能否成立的关键）

**数据集**：三套公开学习日志（ASSISTments 2017 / EdNet-KT1 / Junyi Academy）。它们与本文的姊妹方向共享同一**数据基础设施**，但使用目标不同：本文把日志**仅用于模拟器的参数估计与留出验证**，主要实验对象是模拟器而非原始日志。这一区分是为避免"同一切片的多次使用"——若本文直接在日志上比较策略优劣，就会与共享同一数据基础设施的其他识别目标重叠，构成重复。

**模拟器构建（自足，不以上游未完成工作为前置）**：模拟器由三部分构成——"难度 → 学习增益"的映射由本文在留出日志上自行估计的剂量—反应关系给出；题目难度分布由 IRT 参数生成；遗忘与复习动态由 DSR 式记忆模型生成。该剂量—反应估计与其他方向上的独立估计互为交叉验证，但**不以任何他方结果为前置条件**：即使其他方向尚未产出结果，本文的模拟器仍可自建并自验证。这一设计是为避免"依赖链断裂"。

**模拟器验证（不可省略）**：以留出数据检验模拟器的预测误差，报告三个分布的拟合优度——下一题正确率分布、掌握速度分布、反应时分布。**若模拟器误差过大，必须诚实报告并相应下调结论置信度。** 不执行这一步，一句"你的模拟器是循环论证"即足以拒稿。

### 4.2 基线（子设计一）

（i）现有贪心 + 精确等值匹配；（ii）窗口成功率固定步长；（iii）ε-greedy 独立动作；（iv）UCB / Thompson Sampling 独立动作（10 档）；（v）**Castleman 等（2024）的分层 MAB 智能导师（概念 MAB + 题目 MAB + BKT + MCM 遗忘）**；（vi）本文方法：Lipschitz / 非平稳 Lipschitz bandit，有序动作 + 可提取性状态。

### 4.3 评价指标（子设计一）

累积学习增益（离策略估计 + 模拟器内）；遗憾；心流区内停留比例（以 ∂Φ⁺ 为参照）；掌握所需作答次数；**冷启动期（前 20 次交互）的表现差异**（预期本文方法的最大优势所在）。

### 4.4 识别与离策略评估（子设计一）

在真实日志上以 IPS / DR 评估所学策略与基线策略的累积学习增益，并报告有效样本量（ESS）与权重截断。**如实警告**：现有系统"基本可用"，不应期待数量级提升；本文卖点应为**理论保证 + 冷启动改善**，预期效应量为小到中等（d ≈ 0.15–0.35）。

### 4.5 数据与前置检查点（子设计二）

- **题目侧**：本项目自有中文 K12 题库（差异化资产）+ 公开题库。
- **真值侧**：具备真实学习者响应的题目，经 IRT 标定得到 βⱼ。
- **硬约束**：每道题须有足够真实学习者响应以作 IRT 标定。这会显著限制可用题目数，须诚实报告。

**go/no-go 检查点 C-2**：本项目题库**是否有真实作答**。若无，则退回公开英文数据集、场景/数据新颖性降级，中文路径改投《数据分析与知识发现》或教育技术类刊物。场景差异化的理论内容有三条可被边界地图直接检验的机制：**分词与术语切分**（中文数理题的复合表述会以不同于英文空格分词的方式影响模型对结构的解析）、**答案形式与过程性**（"列式计算""单位换算"等表述使难度信号更多藏在过程中）、**文化语境与生活场景**（人民币、市制单位等场景在英文语料中覆盖稀疏，模型只能依赖表层语言特征）。这三条说明"换数据集"本身不构成差异化理由，须说清语言维度为何可能**改变结论**而非只改变样本。

### 4.6 基线（子设计二）

（i）无先验（冷启动）；（ii）LLM 单点估计先验；（iii）LLM 成对比较 + Bradley-Terry（LLMcompare 式）；（iv）LLM 多模型集成（含重采样增强，Liu 等, 2025 式）；（v）本文的层级贝叶斯校准。

### 4.7 变量与稳健性（子设计二）

标注层：Pearson r、Spearman ρ、QWK、系统偏移、ECE。共识层：集成—人类对齐度与单模型平均—人类对齐度之差 δ（定义见 3.5 节）。决策层：累积学习增益、冷启动期遗憾、N\*。稳健性包括：（i）噪声/温度/提示敏感性（参照 LLMcompare 的噪声注入 < 6% 衰减）；（ii）口径一致性检验（见 3.5）；（iii）合成被试集成在**有/无人类锚点**下的表现差异对照（Liu 等, 2025 的情境 vs 无锚点情境）；（iv）模型规模序列检验（验证"越大越不对齐"是否在中文 K12 上复现）。

### 4.8 预注册与可复现性

**预注册。** 登记两个子设计的假设方向、L 的估计与检验方式（若前提 L 被拒则改用非参数方法）、心流区标定的分位阈值、模拟器验证的通过标准、判据阈值 δ\* 的确定规则、N\* 的估计程序与三条终止条件。若模拟器验证未通过，子设计一按预注册降级为技术报告。鉴于模型迭代迅速、具体数值易过期，子设计二把所有结论表述为方法论与判据，并将预注册与开源评测集作为 artifact 供社区在新模型上重跑。

**可复现性。** 实验以单机环境为主，计算量可控。模拟器、策略实现、离策略评估脚本与随机种子将随研究依托系统的公开归档（Zenodo，版本 DOI 10.5281/zenodo.22719229）一并发布，并附配置文件锁定 IRT 参数、剂量—反应曲线系数、记忆模型参数与超参数搜索范围；另提供**模拟器诊断脚本**，输入留出日志、输出三个分布的预测误差、校准曲线与按能力分层的误差分解，使模拟器的可信度可被独立检验而非仅凭作者声明。所有随机化实验在固定种子下重复不少于 30 次，报告均值与置信区间。

**跨方向边界声明。** 子设计一的模拟器自建自验，不依赖他方结果；三套公开日志与姊妹方向共享同一数据基础设施，但本文只用它们估计与验证模拟器参数，不在其上重复其他识别目标；难度动作的度量只沿用统一的量纲**定义**（非任何结果），本文不重复标定实验、也不以任何他方输出为前置。子设计二的真值由本文在自有/公开题库上独立标定，仅与子设计一共享"难度"概念，不共享任何数值。

## 5 分析计划与检验（预注册）

本节给出**计划执行的检验**与**尚未获得的结果**。所有条目均为分析计划，不是已完成的发现；每项检验均预先写明"何种结果将导致该假设被拒"。

### 5.1 假设 H1：难度选择满足 Lipschitz 连续性

**计划检验**：两类独立证据同时成立——相邻档增益差随档距呈次可加（即 μ(d+2δ)−μ(d+δ) ≤ μ(d+δ)−μ(d)），且跨会话外推误差不随档距线性发散。对前者作凹性检验，对后者作留出会话的外推误差曲线。**若前提 L 被拒**，改用局部 Lipschitz 或非参数方法并如实报告。

### 5.2 假设 H2：有序动作策略优于独立动作策略，尤其在冷启动期

**计划检验**：在校准后的模拟器中，本文方法的累积遗憾低于 UCB / TS（10 档独立动作），且冷启动期（前 20 次交互）的优势最大；与 Castleman 等（2024）的分层 MAB 相比，本文方法在**遗忘显著**（长间隔）的条件下占优，在短会话中差距不显著。以多随机种子下的配对比较与置信区间判定。

### 5.3 假设 H3：心流区的非支配边界 ∂Φ⁺ 为非退化前沿

**计划检验**：在 (错误率, 代价) 平面上，∂Φ⁺ 呈负斜率，固定区间 [0.75, 0.85] 只是 ∂Φ⁺ 在忽略代价维度时的投影；沿 ∂Φ⁺ 移动可改变增益与代价的组合而不产生被支配点。以前沿的非支配性检验判定。

### 5.4 假设 H4：可提取性作为状态产生可检验的结构性预测

**计划检验**：最优难度的漂移方向与命题 M1 一致（可提取性下降时选内在难度更低的题）；命题 M2 的复习/推进切换点在数据中可被定位。以可提取性为调节变量的条件最优动作回归判定，并检验漂移方向是否如 M1 所预测为负——若为正，则 M1 被反驳，须报告并重新审视 μ(·) 的单峰假设。

### 5.5 假设 H5（模拟器验证，前置门槛）

**计划检验**：模拟器在三个分布上的拟合误差在可接受范围内；这一节的结果先于 H1–H4 报告，若不通过则子设计一按预注册降级。

### 5.6 子设计二的假设与终止条件

**H6（边界地图）**：LLM 标注的可用性高度依赖格子——在难度极端分位、含图多步题与主观题上，模型—人类对齐度应显著低于中等难度客观题，并检验中文 K12 是否复现"平均 ρ < 0.5"的悲观派模式。**H7（机器共识）**：δ(n_ens) 显著为正且随集成规模扩大——ρ_ens(human) 不升甚至下降，而模型间一致性持续上升；若成立，多模型集成在难度标注上适得其反，应把集成规模限制在 δ 转升之前。**H8（决策层损失）**：Δ(δ) 在小 δ 时近似为零、超过阈值后快速上升，给出"先验偏差超过该值时不如冷启动"的交叉点——这是子设计二从标注层跨到决策层的关键证据。**H9（N\*）**：N\* 的量级在数十至数百之间，随先验偏差 δ 增大而增大、随题目区分度提高而减小，以模拟 + 公开数据双层验证。**H10（对照）**：无人类锚点时，合成被试集成提高的是模型间一致性而不提高模型—人类对齐度（δ 随集成规模上升）；而在有小样本人类锚点时（Liu 等, 2025 的情境），集成确实提高模型—人类对齐度——这把"集成是否有效"明确系于"有没有人类锚点"。**终止条件（红线）**：若 H8 与 H10 均不成立、且整体结果为纯正面而无任何负面条件，本文应**主动终止**，而非包装成一次成功；该红线在预注册中写死，避免事后择优。

## 6 讨论

### 6.1 理论含义

子设计一的核心贡献不在于提出新的遗憾界，而在于**把难度选择还原为两个可证伪的结构假设（有序性、含记忆状态）**，并指出独立动作建模在这两个假设下是错误的。这一定位把论文的动机从"我们又用了一个新方法"转为"已有方法忽略了两个结构性质，本文证明它们可被证伪并被利用"。C3 进一步把记忆科学从预测接入决策，这是子设计一最不"像现成轮子"的部分。子设计二的核心论点是：**机器共识不等于人类难度**。当模型在标注任务上彼此趋同，其一致性的提高可能来自共享的训练偏差，而非对真实学习者困难的逼近；因此"用多模型投票提高标注置信度"的有效性是有条件的，取决于 δ 的符号与量级。

### 6.2 对系统设计与工程实践的启示

若子设计一的假设得到支持，自适应系统的难度决策不应只依赖题目标签与静态难度带，而应把可提取性作为状态分量，并采用有序动作的探索策略；系统应支持"窄化动作集"（限定可选难度档位）以降低策略空间。对子设计二，可执行结论只有一条：在上线一个 LLM 难度先验之前，先在小规模、有真实作答的题目子集上估计 δ；若 δ 为正且随集成规模扩大，就把集成规模限制在 δ 转升之前，或改用单模型加在线校准。这条规则之所以值得写下来，是因为它与当前工程直觉相反——直觉是"模型越多越稳"，而 δ 恰好度量了这种"稳"是否只是模型之间相互印证。

### 6.3 局限性

**第一，无真实结果，全部为分析计划。** 本文是预注册设计稿，不报告任何点估计或显著性结论；所有"预期"均为计划，投稿前须以实际执行结果替换。**第二，评估可信度受模拟器限制。** 子设计一以模拟器 + 离策略评估 + 模拟器验证三件套应对无在线实验的问题，并在局限中显式声明无在线实验证据；若模拟器验证不通过，须下调结论置信度甚至降级。**第三，C1 为已有理论的适配。** 若只完成 C1 而无新证明，方法新颖性下调，重心须整体移至 C3。**第四，子设计二的真值可得性是硬约束。** 需要带真实学习者响应的题目作为 IRT 真值；本项目自有中文 K12 题库是否有足够响应数据**尚未确认**（检查点 C-2），若无则退回公开英文数据集并失去中文差异化。**第五，无自有被试、无真实部署流量、无基金、无伦理审查资源。** 本文不涉及人类被试的在线实验，真实系统部署流量亦不可得；本项目**无基金资助、无机构部署、无伦理审查资源**，短期不具备执行在线验证的条件。**第六，模型迭代使子设计二的结论易过期**，本文以方法论与判据形式表述并以预注册 + 开源评测集应对；LLM API 调用存在成本（数千元级），可能限制模型与题目的覆盖广度。**第七，两子设计的共同约束是对齐口径。** 子设计一依赖前提 L 与 μ(·) 单峰假设，子设计二依赖 IRT 真值的可比性，两者均须在共同题目子集上作口径一致性检验。**第八，学习成瘾相关测量未验证。** 若本文把动机侧变量（如学习成瘾指数 LAI）纳入努力代价维度或决策层评估，须声明：LAI 五维权重为时间 30% / 动机 25% / 控制 25% / 认知 10% / 功能 10%，其中"控制 + 功能"合计 35% 由自陈测量层供给（`instrument_catalog.py` 中的 SRL-STOP / SLEEP-IMPACT / SOCIAL-IMPACT / TIME-BIAS），未测维度不计入加权并输出 coverage 披露；其题项为**本项目自编、未做信效度验证、无常模、无临床截断值**，属 work-in-progress 工具，不得据此作临床或诊断性推断。**第九，跨方向边界表述须一致。** 子设计一以自建模拟器而非原始日志为主要对象，子设计二的真值由本文独立标定；此声明须与方法章节保持一致，以避免"同一数据基础设施被重复切片用于同一识别目标"的质疑。

## 7 结论

本文把自适应学习中两个被跳过的前提分别正面处理，并把它们组织为两个可独立成立的子设计。子设计一指出"贪心 + 精确等值匹配"的难度选择在两个可证伪的结构性质上失效——动作空间的有序性与记忆可提取性的状态依赖——并据此把难度选择形式化为序贯决策，给出遗憾界适配（C1）、心流通道的二维非支配边界刻画（C2）与以可提取性为 MDP 状态的动作价值形式化（C3）；其护城河收窄到 C3，C1 属"适配而非新证明"，评估以 Castleman 等（2024）的分层 MAB 智能导师为必选 baseline，并把模拟器验证设为不可省略的前置门槛。子设计二把 LLM 难度标注的问题从标注层移到决策层，把贡献落在两个可操作对象上——δ 与 N\*，前者回答"模型群是不是在自我印证"，后者回答"要用多少真实作答才能把它拉回来"——并写死一条终止条件：若实证结果为纯正面而无任何负面条件，应主动终止。

本文是设计稿，结果尚未产生。后续工作有三项：完成非平稳设定下 L 的自适应估计，并把可提取性状态的策略推广到多知识点联合调度；确认中文题库的响应数据可得性，并把 δ\* 的计算流程实现为开源工具以便在新模型上重跑；在具备条件时以"窄化动作集"范式执行小规模真人实验，并用在线实验检验 N\* 的模拟估计是否可靠。
