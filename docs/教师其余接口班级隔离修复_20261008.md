# 教师其余接口班级隔离修复（第十轮，2026-10-08）

第九轮修复班级列表、作业和热力图后，本轮继续检查教师端其他学生数据接口。原先学生详情与单人分析按 ID 直接读取；建议、全班分析、难度建议和干预计划读取全部活跃学生；告警列表与处理也没有所属班级限制，难度调整可修改任意用户。

统一 student_scope 与 owned_student 约束：普通教师限于 teacher_id 属于本人班级内的活跃学生；管理员可管理活跃学生。学生详情、单人分析、建议、全班分析、难度建议、干预计划、告警列表与处理、难度调整均使用该范围。未分班、其他班级、非学生或非活跃用户不推定为某教师学生。越权单人/修改请求返回 404，难度请求仅接受 1–10，超范围返回 422。

数据库测试用两个班级的错误作答与告警，验证：他班详情及分析被拒；各类建议仅有本班学生；全班分析难度分布只有本班 5 次作答；他班告警不列出、不允许解决；他班难度修改被拒且原值不变；本人学生可查看、处理告警并持久化偏置；管理员可访问他班。原数据真实性测试补充实际教师、班级与学生归属，仍验证历史统计计算，不放宽到管理员绕过教师范围。
