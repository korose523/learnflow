# 学生复习流程修复与验收

2026-10-08，续第五轮项目修订。当前稿件继续采用公开数据、离线评价和模拟；本轮改善普通应用的复习功能，没有新增真人参与或学习效果证据。

## 发现的断点及修复

主页原来的“错题再练”进入普通 `/learn`，没有消费到期复习记录。现在改为“到期复习”，进入 `/student/reviews`。页面显示实际到期题目、数学内容和题目等级，提交答案后显示服务器反馈、题目讲解及下次复习日期。加载和提交失败有可见提示，失败提交不会在界面上当作复习完成。

新增 `/api/v1/student/reviews/{review_id}/answer`，由服务器绑定记录与题目并判分。仅学生本人可以提交，未到期、已经完成或题目未获批准的记录不可提交；已完成记录再次提交返回冲突。旧记录的完成日期和结果，以及新的计划和作答记录在同一数据库事务中保存；出现异常时回滚。普通练习更新一条现有待复习计划，避免每次作答都追加新计划。

到期列表及主页数量仅包括当前已审核题目。列表不暴露标准答案；讲解在实际作答后返回。同时间记录的游标同时包含时间和 ID，避免原来的仅按时间分页跳过同一时刻的其他记录；无效游标返回明确错误。

## 证据与限制

数据库测试核对真实判分、完成旧记录、安排未来复习、重复提交拒绝、归属权限、未到期及未批准题目、同时间分页、普通练习计划刷新。浏览器验收使用新建临时 SQLite 数据库和虚构账号，将一条虚构复习记录的日期设为过去；这是技术夹具，不是实际等待了一天的用户研究。

间隔服务采用固定间隔和正误调整规则，没有拟合个体遗忘曲线。复习次数的启发式指标不能当作校准掌握度或记忆测量。没有把“功能可运行”写成“提升学习效果”。

旧版本可能遗留多条待复习计划。本轮不连接或清理真实数据库、不虚构其历史完成日期；普通练习刷新现有一条计划，没有承诺自动清除所有旧重复记录，也没有新建跨数据库唯一性迁移。并发与长期使用下的调度一致性仍需继续核对，不能仅凭顺序重复提交测试证明所有并发场景。

本轮验收具体通过数量以保存的测试日志和 JSON 为准。当前完整项目与投稿目标仍未完成：教师作业、家长限制、题库完整题型和题干质量、页面全部科学主张、独立种子命令及部署、M2 外部工程证据和最终投稿事实都仍需继续。

## 本轮实际结果

后端全量 1012 passed、16 warnings；复习专项 4 passed。新数据库复习浏览器场景 5 项通过，普通出题/审核/学习场景 12 项回归通过，未记录页面脚本错误。TypeScript 与生产构建通过。临时服务由验收器停止，临时库删除。上述证据不覆盖所有长期并发、旧库清理或其他角色功能。
