# 答错恢复流程修复与验收（2026-10-08，第八轮）

恢复接口原先只检查题目存在，未检查审核或本人错误作答，并在每次选择恢复选项时再次更新宠物属性。它还声称跳过会标记待突破并安排周末复习，实际没有该持久化行为。

当前 `/api/v1/student/recovery-choice` 仅接受 `watch_tutorial`、`retry`、`skip`，其他值返回 422；题目未审核返回 409；本人在该题没有作答或最近一次作答正确返回 409。最新记录按创建时间、ID 排序。兼容原请求格式，无数据库结构迁移。

恢复流程读取宠物当前状态，不修改属性、级别或情绪，也不新增作答记录。奖励仍由服务器判分后的提交答案流程产生。因此重复打开讲解或选择重试不再叠加奖励。提示文字仅描述可执行的下一步，不声称用户能力增长或已安排未实现的周末计划。

专项测试使用真实数据库和判分器，验证：非法选项；未作答；本人错误作答；重复讲解、重试和跳过后属性不变且作答数不增；题目撤回审核；其他学生不能借用作答记录；正确作答后不能继续使用错误恢复流程。共 6 passed，22.09 秒（包括已有审核和复习测试）。

本轮完整后端及浏览器结果以第八轮证据包日志为准。浏览器脚本验证教师上传、管理员审核、服务器判分、错误后阅读讲解与重试；不涉及真人研究。它不验证所有长期、并发或跨设备流程。

工程证据可用于 M2 的功能正确性及约束说明，不作为学习效果、外部软件泛化或伦理批准依据。教师作业/班级权限、家长限制、长期调度、其他页面证据主张及论文投稿适配仍待完成。
