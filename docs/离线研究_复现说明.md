## M1 配对判据比较

运行 `python results/m1/run_a1a2_fit.py`。它从本地 Junyi CSV 读完整 16,217,311 行，以学生 crc32 奇偶划分 A/B，B 半每题至少 500 条、最多保存前 1,500 条用于 25 轮 1PL 拟合。A 半分别构造七信号融合和失败率。输出 `results/m1/m1_criteria_results.json` 含对齐题目向量、点估计和 2,000 次配对题目 bootstrap，种子 20261007。DBE A2 调用共享 dbe_signals，与 O4 保持全交易口径。

A1 使用 rank/n、1e−9 截断的链接，A2 使用 (rank−0.5)/n、1e−4 截断的链接，信号数也不同。二者不是严格的仅判据改变实验。bootstrap 条件于拟合向量，不重拟合 IRT，不等于学生级或参数完整不确定性。

运行 `python results/code/m1_instability.py` 复现合成尺度实验。有效贡献定义 π_k=w_k Cov(z_k,S)/Var(S)。严格递增共同校准不变性不代表 π=w。运行 `python results/m1/plot_criterion_differences.py` 从实际 JSON 输出 PDF、SVG、300dpi PNG，禁止手改图中数值。

## 现成 K12 题库

先按 [XES3G5M 官方项目](https://github.com/ai4ed/XES3G5M) 与许可取得数据。当前本地已有该发布版。运行 `python scripts/k12/prepare_xes_bank.py` 输出完整逐题元信息 `results/k12/xes_question_bank.json` 和统计/输入哈希 `xes_bank_inventory.json`。无学生 ID 写入输出。公开 train/test 学生不重叠；仅使用 question-level 序列，不能把 KC 扩展后的记录数当原始交互数。

两区均至少30条记录的4,470题，仅比较训练区平滑失败率与测试区观察失败率。此检查表明观察率跨学生可复现，不提供 IRT 难度或最优学习目标。题库答案和解析不可输入模型提示作为无泄漏评价的一部分；正式后续评级应独立抽取 content/options，保留盲测答案。

3,209 题只是无图单数值的格式初筛兼容集合，未逐题专家校对。图题、单选、多空题和非数值答案需专门渲染与判分。完整题库不直接导入生产数据库；需要本地演练时另用明确命令和测试库。
