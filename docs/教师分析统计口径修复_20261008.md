# 教师分析统计口径修复（第十一轮，2026-10-08）

本轮继续回应教授关于应用数据与论文主张关系的意见，不把演示值写成观察值。

- 班级 active_students 原来累计当日作答条数。同一学生作答三次会显示三名活跃学生；现在直接查询当前可见学生的当日 UTC 作答，按 user_id 去重。查询不受最近 500 条分析样本的截断影响。
- 单人 weekly_attempts 原来取最近 100 条作答总数，可能包含多周旧记录且截断真实总量。现在按查询时刻向前七天（含起点与终点）独立计数，排除未来记录。它表示观察到的滚动七天作答次数，不是自然周或学习收益。
- 单人 skip_ratio 原来硬编码为 0.1。当前数据库没有完整可用的跳过事件分母，本轮返回 null，服务风险规则在缺失时不触发跳过率判断。null 表示未测量，不解释为零跳过。单人 total_attempts 改用完整计数，不取截断样本长度。

数据库测试含同一学生三次今日作答及 105 次十天前作答，验证 active_students=1、weekly_attempts=3、skip_ratio=null；连同权限、统计与服务原有测试，专项最终 32 passed（8.42 秒）。其他趋势与平均难度仍基于明确的最近样本，未把它们改称完整历史估计。

本轮修改服务源后，M2 当前服务树静态审计由原脚本重新生成；历史冻结审计不覆盖。结果输出来自脚本，没有手工修补 JSON 数字。
