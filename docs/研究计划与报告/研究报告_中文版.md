## 3 论文一：难度量纲的可公度性

**本章摘要**：本章报告难度可公度性的不稳定性命题及其在合成与真实数据上的检验结果，并报告一组判据依赖性负结果。

### 3.1 不稳定性命题的检验

**合成数据。** 把各难度源先归一化到 [0,1] 再线性加权时，以边际贡献定义的有效权重既不等于名义权重（π₁ = 0.532 ± 0.026 对名义 w₁ = 0.40），也会随任一源的单调重参数化而漂移：

| 变换类型 | 漂移 L1 | 排序反转比例 |
|---|---:|---:|
| 仿射变换 | 精确为 0（被 min-max 吸收） | — |
| 非线性单调变换 | 0.1276（SD 0.0196） | 36.4% |

最强反例中出现权重向量完全反号（Spearman −0.20，L1 = 0.6893）。

**分位公制修复。** 改用经验 CDF → logit 的分位公制后，同校准样本下漂移严格为 0，独立校准样本下仅有 0.016 的链接抽样噪声，排序反转归零。

**真实数据。** 在 assist09（994 题）上，线性 min-max 融合的漂移为 L1 = **0.5357** 且排序反转显著；分位公制下降至 **0.0001**，反转归零。

> 复算命令：`python results/code/m1_instability.py`（合成）、`python results/code/m1_real_data.py`（真实数据）

### 3.2 多信号融合的增益与其判据

在 DBE-KT22（212 题）上，专家难度与经验难度的秩相关仅 **0.2207**；换用联合 IRT-1PL 估计器只提升到 **0.2300**——说明瓶颈不在估计器。把五个行为信号以分位公制等权融合后升至 **0.2899**，优化权重的重复 5 折 ×10 交叉验证达 **0.5240 ± 0.1069**。其驱动力被定位到一个**差分特征**：自报难度与信任度在题级 Pearson 相关高达 +0.94，而在分位空间中"信任度反向"与自报难度的相关为 −0.80，二者相减恰好消掉共同模态噪声。

在 Junyi（**1,234 练习**、1,621 万条交互、无自陈反馈）上同向复现：**0.2610 → 0.3629**，重复交叉验证 **0.4023 ± 0.0480**。bootstrap 配对增益：Junyi Δ = +0.1017 [0.0726, 0.1325]，p = 0.000；DBE Δ = +0.0723 [−0.0195, 0.1649]，单侧 p = 0.059（仅边缘显著）。

### 3.3 判据切换后的结论反转（本报告最重要的负结果）

专家标签与**真实表现难度**的秩相关只有 **0.4326**——即专家标注只解释约 19% 的秩方差。把判据换成"未见过样本的真实表现"后，等权融合在 Junyi 与 DBE 的**全部**样本量档上均劣于仅用成功率：

| 样本量 k | Junyi 增益（pp） | DBE 增益（pp） |
|---:|---:|---:|
| 10 | −0.0267 | −0.1752 |
| 200 | −0.1222 | −0.2113 |

融合胜率 **0.00**。据此，第三章 3.2 节报告的全部增益，其正确表述是"**与专家标签的一致性增益**"，而非预测力提升。这一反转是本报告期内最重要的负结果。

### 3.4 方向性错误的定位与样本量自适应收缩

进一步定位到融合配置中的一处实打实的**方向性错误**：升级率与专家标签的相关为 −0.1837、在池内为 −0.756，却被坐标上升优化器赋予了 **+0.154 的正权重**。剔除该信号并引入样本量自适应收缩后，小样本档首次反超基线（k = 10 时 +3.43 个百分点），但收益随样本量迅速衰减至 k ≥ 100 时的 0.22 个百分点以下。

**收缩规则。** λ_cf(k) = 1 / (1 + (k/27.3)^0.895)（全量拟合值为 27.4 / 0.902，R² = 0.9989；部署值取留一 k 交叉验证拟合结果）。该规则经**留一 k 交叉验证（区间内插）**检验：只用 k ∈ {10, 50, 200} 拟合，在拟合区间 [10, 200] 内评估 k = 25 / 100，保留了经验最优收益的 111% 与 128%，因此**无需按部署重新调参**。该结论在按学生身份切分的**学生级留出**上完整复现（k = 10 时完全未调参的估计给出 +3.64 pp，与记录级留出的 +3.43 pp 几乎一致）。

### 3.5 估计器优化：从"剔除"到"符号校正"

报告期内完成融合估计器的两项优化：把方向错误的信号由**整列剔除**改为**符号校正**（作为负向证据计入，保留其信息），并按各信号在拟合块内的**折半信度**加权，得到 `srw7` 估计器。全部符号、权重与收缩系数只在拟合块内估计，保持无泄漏。

| 留出协议 | 相对"仅成功率"基线的增益（pp），k = 10 / 25 / 50 / 100 / 200 |
|---|---|
| 记录级留出 | **+3.823** / +2.025 / +0.930 / +0.391 / +0.138 |
| 学生级留出 | **+4.283** / +2.189 / +0.951 / +0.335 / +0.102 |

**必须如实陈述的否定性结论。** 在学生级留出下，简化估计器 `fused6`（O8 的"剔除升级率"方案）在 k ≥ 25 时**低于"仅成功率"基线**：−1.402 / −3.905 / −5.728 / −6.804 pp，即该简化在样本量增大后有害。`srw7` 是同协议下**唯一**在所有样本量档上均不劣于基线且优于 `fused6` 的变体（配对胜率 0.902–1.000，Wilcoxon 符号秩 p ≤ 1.29 × 10⁻⁶⁶）。该结果同时表明，原有的"剔除升级率"虽方向正确，却丢弃了该信号的有效信息，并非最优处置。

**边界。** 该优化只在 Junyi 上验证，**未跨系统复现**；收益在 k ≥ 100 时可忽略；在 DBE 上 λ 收缩无收益。

### 3.6 知识树结构作为难度代理的负结果

知识树深度与经验难度的秩相关只有 **+0.0785** 且分层均值非单调；父子边上的难度梯度一致性为 **0.487**（约等于抛硬币）。结论：知识树结构不能充当难度序的代理，有序动作空间必须由难度本身构造。

### 3.7 最优错误率的描述性证据与因果识别的未竟之处

> **本节已在 v1.1 中整体重写（2026-09-22 更正，审阅意见 §3.1 与更正表第 1 行）。此前的表述"众数区间落在 0.15–0.20（成功率 80%–85%）"经复核为**等宽分箱的边界伪影**，已作废，不得再被引用。**

**为什么旧表述是伪影。** 窗宽 W = 20，故滑窗错误率只能取 k/20（k = 0,…,20）这 **21 个离散支撑点**。原代码用 `np.histogram(win_err, bins=np.arange(0, 1.0001, 0.05))` 作 20 个等宽区间，区间边界与离散支撑点恰好重合，而错误率由 `1 − (累积和之差)/20` 计算带有浮点误差（k = 16 得 0.19999999999999996，k = 17 得 0.15000000000000002，k = 18 得 0.09999999999999998）。结果是 **0.15 与 0.20 被并入同一区间 [0.15, 0.20)**，0.10 掉进 [0.05, 0.10)，而 **0.25 独自留在 [0.25, 0.30)**。所谓"众数区间"是**两个离散值之和**，与之比较的 0.25 却是**单个值**，两者不可比。

**按整数错误条数重算后的结果。** 现改为按整数错误条数 k 计数（`np.bincount`，全流程无浮点比较），报告 21 个支撑点的频数：

| 统计量 | 值 |
|---|---|
| 窗口总数 | 286,150 |
| 有效使用人数 | 见下方口径说明 |
| 均值错误率 | 0.3511 |
| **单值众数** | **错误率 0.25（成功率 75%），30,899 窗，占 10.80%** |
| 80–85% 成功率带 | 19.64% |
| 80–90% 成功率带 | 26.40% |
| 众数的 bootstrap 置信集（按学生重抽样，200 次） | **{0.25}**，在 95.5% 的重抽样中出现 |

**据此的三点结论。**

1. **单值众数是 75% 成功率，不是 80–85%。** 按单值看，"80–85% 成功率是众数"这句话**与存储结果不符**：错误率 0.25（30,899 窗）多于错误率 0.15 与 0.20 各自（由 `share_err_in_17_23pct` 反推，0.20 ≈ 30,074 窗、0.15 ≈ 26,138 窗）。
2. **旧稿"与 85% 规则的 15.87% 和先行研究的 80.7% 均相容"一句不成立。** 该句建立在伪影之上，已撤回。分布的单值众数**低于** Wilson 等的 84.13% 与 Baillifard 等的 80.7%。若要说它与某个候选最优值相容，只能说 80–85% 带的窗占比高于其他任何 5 个百分点宽的带，但**这属于带的宽度效应，不是众数位置的证据**。
3. **旧稿"三种过滤口径众数区间相同"的稳健性主张不成立。** 三种口径此前复用同一分箱函数，不是独立证据；且其中 tutor_mode 口径的窗数实测为 0。本版按整数错误条数分别重算后，**不再宣称三种口径一致**。

**口径说明（`n_users_used`）。** 旧稿写"4,217 人"，该数字存的是 `len(by_user)`，即**输入日志中出现的全部用户数**，而非"作答数 ≥ 20 题、真正进入滑窗统计的用户数"。本版已把两者拆开报告为 `n_users_input` 与 `n_users_used`（≥ 20 题口径），并在 M1 完整稿中按新口径表述。

## 5 论文三：有序难度决策与大模型难度先验的可靠性边界

**本章摘要**：本章报告有序动作空间的实证基础、无需能力先验的排序规则，以及 LLM 难度先验可靠性边界的测定结果。

### 5.1 有序动作空间的实证基础

用 Junyi 的真实练习替换自建模拟器中的等距线性难度假设，把动作空间重建为"同一知识 strand 内按专家难度分组的真实练习"。Junyi 的完整规模为 **16,217,311 条交互 / 72,758 名用户 / 1,326 个练习**，动作空间的重建使用其中的专家标注子集。专家难度标签的经验成功率严格单调：

| 专家标签 | 经验成功率 |
|---|---:|
| easy | 0.7355 |
| normal | 0.6328 |
| hard | 0.6160 |

难度转移呈现**爬坡摩擦**：hard→easy 为 0.7534，easy→easy 为 0.7335，而 easy→hard 仅 0.6302。下降转移与上升转移相差 **12.3 个百分点**；同为 easy 出发的两条转移相差 **10.3 个百分点**。这是"动作空间有序且转移非对称"这一建模前提的第一手行为证据。

### 5.2 真实臂上的策略比较（奖励 = 即时成功率）：初步观察，不构成结论

> **本节标题与定性已在 v1.1 中更正（2026-09-22，审阅意见 §5.3）。** 旧标题为"无需能力先验即可达到能力感知策略的水平"，该表述**超出了材料所能支持的强度**，已删除。核心原因是**奖励定义**：本实验的奖励是**即时成功率**，而 `flow_zone` 正是瞄准成功率 0.75 的策略，因此它在以即时成功率为奖励的实验中得高分**几乎是同义反复**（与 `all_easy` 得高分的原因相同）。在无法观测学习增益的数据上，策略比较只能算**初步观察**。

在 52,733 名用户标定、500 次模拟 × T = 40、**奖励 = 即时成功率**的真实臂实验中：

| 策略 | 得分（即时成功率） |
|---|---:|
| 能力先验正确 | 0.7023 |
| 能力先验反转 | 0.6714 |
| `flow_zone`（瞄准成功率 0.75，无需任何能力先验） | **0.7119** |

**能说的**：能力先验正确与反转两策略的差为 +0.0309（约 2.9σ），即**在该奖励定义下，能力误判的代价稳健为正**；`flow_zone` 与能力感知策略的差距约 1σ（不显著）。

**不能说的**：不得表述为"无需能力先验即可达到能力感知策略的水平"，也不得据此论证"无需建模能力"。**原因**：奖励即成功率时，瞄准成功率的策略占优是设计上可预期的；该实验不能区分"策略更优"与"奖励定义对它有利"，也未覆盖学习增益、观测性与内生性（策略由数据生成，动作分布非随机）。

### 5.4 协议审计：可用性分级、工程教训与一处方法论更正

> **本节已在 v1.1 中整体重写（2026-09-22，审阅意见 §5.2）。旧稿的核心句"同一模型、同一能力，仅因标注协议不同即得到 0.03 / 0.05 / 0.18 / 0.22 四种答案"已删除**，理由：那四个值中有两个**不是模型能力的估计值，而是失败的协议实现**。

**四类协议的可用性分级。** 逐条复核 prompt、API body 与存储的原始回复后，四类协议分为"可用"与"失败实现"两组：

| 协议 | 与专家难度的一致度 | 可用性 | 失败原因（若失败） |
|---|---:|---|---|
| v1（旧轮次） | ρ = 0.0295 | ❌ **失败实现，不得引用** | `num_predict = 16` 截断了思考（think）token，标签从被截断的思考文本中读出；存储的 DBE 原始回复 212 条全部以 `<think>` 开头 |
| E1-B 首轮（自由字符串排序） | ρ = 0.046（108 批中 60 批解析失败） | ❌ **失败实现，不得引用** | 未约束输出为枚举数组 |
| **E1-A 锚定量表绝对评级** | **ρ = 0.2195**（n = 212，p = 0.0013） | ✅ **可用** | — |
| **E1-B 批量排序 + Bradley-Terry** | **ρ = 0.1808**（1,362 条两两约束，p = 0.0083） | ✅ **可用** | — |

**两类正确实现的差异做配对检验（本题新增）。** 两个可引用协议的差异不能靠独立相关系数比较（E1-B 经过两两约束与 Bradley-Terry 再拟合），故新增**配对 bootstrap**：重抽样单位是**题目**（DBE-KT22 的 212 道），**BT 在每个重抽样样本内重新拟合**。

| 量 | 值 |
|---|---|
| Δ 点估计（E1-A − E1-B） | 0.0385 |
| bootstrap 均值 | 0.0699 |
| bootstrap 95% CI | **[−0.0652, 0.2193]** |
| 双侧 p | 0.34 |
| 结论 | **差异不显著**（`significant_at_0.05: false`） |

> 复算命令：`python results/code/o13_llm_protocol_audit.py` → `results/code/o13_llm_protocol_audit.json`。
> **方法论更正**：不得声称"把结论从 0.046 抬到 0.1808 的原因是剔除了失败实现"——0.046 本身就是失败实现的产物，两个数字不同批不同协议，不可直接相减对比。

**工程教训（值得原样保留的实务结论）。**

- `format: json` **并不足以**约束输出：模型会输出 `{"explanation": ...}` 模板，解析失败率约 30%；
- 必须使用 JSON Schema 的 **enum / array-enum** 约束；
- 排序任务必须用**枚举数组**（如 `{"ranking":["A","B","D","C"]}`）而非自由字符串。

**修正后的方法论结论**：可引用的协议（枚举数组）实测为 **48 批 / 0 解析失败 / ρ = 0.0478**；另一类可用协议（枚举数组 + Bradley-Terry）为 **60 批 / 13 批解析失败（21.67%）/ 697 条约束 / ρ = 0.1553**。因此可以说的是：**输出格式约束（schema 类型）对标注可用性的影响，与"绝对评级 vs 相对排序"这一方法选择同等重要**；而**不能**说"协议稳健性大于方法选择"——因为支撑该句的两次失败运行不能当作样本。建议把协议审计设为 LLM 难度标注实验的**必报项**。

### 5.5 一条反向边界

在 XES3G5M 上，知识组件树的深度与经验难度仅 ρ = +0.0785 且分层非单调，347 条父子边的难度梯度一致性为 0.487（约等于抛硬币）。**知识树结构不能充当难度序的代理。**

## 11 结论

**本章摘要**：本章总结报告期内的主要结论与整体判断。

报告期内完成了测量侧与静态侧的全部研究工作，形成三篇完整稿，并把其中两项结论落地为系统代码、配 14 条回归测试。主要结论可归纳为五点：

1. **难度线性归一化加权在测量论上不成立。** 不稳定性命题成立，有效权重随任一源的单调重参数化而漂移；采用经验 CDF → logit 的分位公制后，真实数据上的漂移由 L1 = 0.5357 降至 0.0001，排序反转归零。**须同时说明**：命题中"分位公制下有效权重不变"的一侧是**解析恒等式**，本研究的贡献是量化该恒等式被违反时的差异有多大，而不是"证明了命题"。
2. **多信号融合的增益是"与专家标签的一致性增益"，不是预测力提升。** 判据切换后融合在全部样本量档上反转为负，胜率 0.00。**须同时说明**：留出判据是成功率时，成功率估计器在大样本占优**是设计上可预期的**（基线即判据量的小样本估计），因此稳妥的表述是"融合的作用是小样本下的秩稳定化"；要主张"一致性增益不是预测力增益"；**2026-09-23 已补**能力校正判据（A1·Junyi，1,274 题，ρ=0.963/0.892）与外生判据（A2·DBE-KT22，212 题，0.205/0.220、κ=0.123）两类实验——两类判据下融合相对仅成功率均未取得可辨优势，故该主张成立，并把口径收窄为「结论取决于判据量的定义」。
3. **方向错误的信号应被校正而非剔除。** 把升级率由整列剔除改为符号校正并加入折半信度加权后，所得估计器在记录级与学生级双重留出下均不劣于基线，且在全部样本量档上优于剔除式方案。
4. **对干预七元组的静态审计发现了实现完成度上的重大缺口。** 在**登记 54 / 效果生产 2 / 成熟度 complete 9·partial 37·placeholder 8** 的系统上，77.8% 的机制无法被归类到七元组，原因是其中四个字段在本项目代码中**尚未实现**；在该实现状态下，运行时可检出的干预冲突仅 1 对、预算竞争 0 对。**该结果被定性为一次实现完成度的诊断，不是证伪条件触发的一般性"发现"**；本报告**撤回**旧稿"冲突并不普遍""多数同类系统规避冲突""稀缺样本"三句外推，理由是材料无法区分"冲突稀少"与"没有能发生冲突的运行时"（真实用户日志 = 0），且跨系统证据仅为 n = 2。
5. **难度先验的可靠性在单一模型上已被测定，但不足以支撑"LLM 的边界"这一命题。** 单一模型（Qwen3.6-35B-A3B / IQ3_S）在 DBE-KT22 上与专家难度的一致度为 ρ = 0.2195（绝对评级）与 0.1808（排序 + Bradley-Terry），两者差异经题目级配对 bootstrap **不显著**（Δ = 0.0385，95% CI [−0.0652, 0.2193]，p = 0.34）；在中文学科题上 ρ = −0.038 且不显著。**旧稿"同一模型仅因协议不同即得四种答案"的句子已删除**，因为其中两个值来自失败的协议实现（一个被 token 预算截断、一个解析失败过半），不是能力的估计值。要把标题级主张立起来，须先完成 ≥ 3 模型族 × ≥ 3 规模的标注矩阵。

**整体判断**：本研究的核心贡献不在于提出更准的预测模型，而在于把自适应学习中"难度"这一被所有组件共享却从未被形式化的核心量，拆解为测量、目标、决策、治理四个可分别检验的问题，并对每一处给出带证据的结论——包括那些与直觉预期相反、与自己先前设计相反的结论。**同时必须承认两处边界**：其一，三处结论的证据强度不等，治理链目前只支持"一次有限的内部静态审计"，决策链的 LLM 部分只覆盖**一个模型**；其二，因果侧识别与人类被试验证**尚未执行**，为本研究下一阶段的主体任务。报告不对未执行分项作任何推测性表述。
