## 摘要

本研究检查自适应学习中“难度”的测量尺度、目标正确率、离线模型先验和干预实现。已完成的证据来自外部公开日志与 LearnFlow 内部静态审计；尚无 LearnFlow 真实被试数据。测量实验说明融合估计器的优势依赖判据：教师标签下，DBE-KT22 的等权融合相关为 0.2918，成功率为 0.2204；Junyi 的独立 B 半 IRT 题目参数下，A 半成功率为 0.9541，融合为 0.8923。assist09 错误率 0.15–0.35 占 49.3% 的窗口，2,000 次学生级重抽样的众数集合为 {0.25, 0.20}，不能据此确定最优练习正确率。当前投稿优先评价难度尺度与离线判据。目标正确率对人类学习的独立后测实验保留为后续选项，不在本轮执行。人类实验、因果策略第 2 版和模型 API 扩展均尚未执行。

## 1 研究问题与范围

RQ1：在不同尺度的难度信号间，融合规则能否保持单调重参数化下的排序和有效权重？融合优势是否随独立判据而改变？

RQ2：不同目标练习正确率是否导致不同的一周延迟测验提升？85% 是待检验条件，不能作为已知最优值。

RQ3：已测本地开放权重模型的题目评级能保持多少教师难易顺序？这一结果能否外推，须由扩展评价而非措辞判断。

RQ4：LearnFlow 的干预 schema 与封存代码实现有哪些缺口？本问题定位为内部实现诊断，不估计真实用户冲突频率。

学位论文的主题是难度的测量与评价。LAI 自编量表无信效度证据，属于附属工程模块，不进入论文测量贡献，也不向实验被试展示健康或风险结论。

## 3 研究方法

尺度实验在共同校准下使用经验分位链接检验严格递增变换不变性；不把秩不变这一数学恒等式称为新发现。主要实证对象是线性归一化融合发生漂移的幅度与边界。

判据实验将估计与评价分开。A1 在 A 半估计成功率和融合，以 B 半拟合的 IRT 题目参数为判据。A2 与 O4 共用全交易、反馈均值、有效时长和平均秩链接的 DBE 信号定义。旧缓存的排除隐藏交易口径只用于明确标注的历史探索分析，不能与全交易结果配对。

模型评级报告 Spearman、Kendall τ_b 与顺序 AUC。顺序 AUC 只比较教师标签不同的题对，模型并列计 0.5；τ_b 的单变量并列计数排除双重并列。Jaccard@k 在三级标签下无法唯一确定最难 k 题，暂不报告。

本章为执行前草案。以下每个研究问题均列出评价问题、独立判据、数据划分、比较对象、指标实现、分析样本、对照、解释分支、预注册、伦理日程十项；未确定项不会被表述为已批准方案。

### 4.1 RQ1 测量

| 项目 | 执行前规格 |
|---|---|
| 评价问题 | 同一融合相对成功率基线的优势是否随独立判据改变方向 |
| 判据 | 独立教师标签；B 半 IRT 题目参数；另列留出真实作答率 |
| 数据与划分 | 学生 A/B 固定划分；题目筛选与校准参数只用估计区 |
| 比较对象 | A 半成功率、等权融合；优化权重另列，避免训练评价混用 |
| 指标与实现 | 含平均秩的 Spearman；共同信号定义；核对输入样本和方向 |
| 分析与样本 | 全部符合既定筛选的题；配对题目级 bootstrap 至少 2,000 次；分析族统一报告 |
| 对照 | 人为构造的已知排序用于程序测试；无关标签置换只检验实现，不作为人类学习阳性对照 |
| 解释分支 | 融合在两判据均胜则支持该范围内优势；反转则报告判据依赖；均未确认则不宣称改善 |
| 预注册 | 已执行分析标明回顾性；新增设计必须在执行前固定，不能追认既有结果 |

3. 按被试和主题存储目标条件，目标值作为参数，记录预测和实际正确率；能力模型及校准方法须执行前选择。
4. 前测、练习、后测和一周延迟测验阶段分别记录，题目互不重叠。
5. 实验条件界面一致，关闭游戏化奖励、学习健康分和风险标签。附属量表不能用于告知临床或健康状态。
