## 2. 模型族分类法（≥3，当前 4 族）

| 族 ID | 名称 | 代表基座（候选，待评估） | 架构 |
|---|---|---|---|
| F1 | Qwen 系（Alibaba） | Qwen3-3B / 14B / 35B-A3B(MoE) / 235B-A22B(MoE) | dense + MoE |
| F2 | Llama 系（Meta） | Llama-3.x-3B / 8B / 70B / 405B | dense |

| 档 ID | 参数范围（总参数，十亿） | 说明 |

| S1 | < 7B | 小模型 |
| S2 | 7B – 30B | 中模型 |
| S3 | 30B – 70B | 大模型（qwen36 落此档） |

MoE 模型按其**总参数**归档（如 35B-A3B 归 S3；671B 归 S4），与激活参数分开记录于 `architecture` 列。

## 4. 标注 schema（单元格字段）

`results/m3/m3_model_scale_matrix.csv` 列：

```
model_id, family, scale_tier, params_billions, architecture,
eval_status, datasets, protocol,
parse_rate, spearman_rho, accuracy, cohen_kappa,
reliability_verdict, source_anchor
```

- `eval_status`：`EVALUATED`（已用同批题目 + 同审计协议实测）或 `NOT_EVALUATED`（外部待补）。
- **度量口径对齐 M3 稿 §5.4**（同一套审计协议，避免口径漂移）：
  - `parse_rate`：协议解析率（须按**返回形态**分层报告，见 §5.4 表 5 教训）；
  - `spearman_rho`：与专家标签（DBE）/ 经验四分位（XES）的 Spearman ρ；
  - `accuracy` / `cohen_kappa`：绝对评级一致性（κ 偏低因边缘分布偏 easy，见 §5.4）；
  - `reliability_verdict`：可用弱 / 不可用 / 题型依赖 / 不可跨题型迁移等定性结论；
  - `source_anchor`：产物 JSON 或稿节锚点（如 `results/code/o13_llm_protocol_audit.json`）。
- **信度门槛（参考 A4）**：`spearman_rho` 须带题目级配对 bootstrap 95% CI；EVALUATED 单元格缺 CI 视为不完整。

## 6. 门禁脚本 `verify_m3_matrix.py`

### 6.1 结构层（必须 PASS，否则 exit 1）

- `MODEL_FAMILIES` ≥ 3 项、`SCALE_TIERS` ≥ 3 项（分类法成立）；
- 矩阵模板 CSV 存在且每 `EVALUATED` 单元格带 `parse_rate` + `spearman_rho` + `source_anchor`、
  每 `NOT_EVALUATED` 单元格这些字段为空（不虚构数值）；
- 单元格 `family` / `scale_tier` 均落在分类法内。

### 6.2 自测（必须 PASS）

- 合成矩阵（≥3 族 × ≥3 档，含 1 个 EVALUATED + 若干 NOT_EVALUATED）→ 校验通过；
- 合成矩阵若族数 < 3 → 校验失败（证明门槛生效）；
- EVALUATED 单元格缺失 `spearman_rho` → 校验失败；NOT_EVALUATED 单元格误填 `spearman_rho` → 校验失败。

### 6.3 复算命令

```bash
# 骨架 + 模板结构校验（本会话可跑，纯标准库）
python results/m3/verify_m3_matrix.py
# 真实多模型评估后（外部执行，补全 CSV 再门禁）
python results/m3/verify_m3_matrix.py --matrix results/m3/m3_model_scale_matrix.csv
```
