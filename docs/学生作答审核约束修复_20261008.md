# 学生作答审核约束修复（2026-10-08，第七轮）

此前下一题与到期复习查询会过滤未审核题，但 `/api/v1/student/submit-answer` 和兼容入口 `/api/v1/student/attempt` 只检查题目是否存在。知道未审核题的 ID 后仍能触发判分和作答副作用，这不满足教师上传—管理员审核—学生使用的约束。

两个提交入口现在读取题目当前审核状态；未通过审核返回 HTTP 409，未知 ID 仍返回 404。检查发生在学习编排器调用前，避免该次请求写入作答、奖励及复习调度。

`test_all_practice_routes_enforce_current_task_approval` 使用临时数据库和真实判分器，覆盖两个入口的未审核拒绝、未知题目拒绝、拒绝后零作答且原复习记录未完成，以及通过审核后两次正常服务器判分。这不是真人实验，也不证明题库题目数学质量或长期学习效果。

专项测试：5 passed（21.80 秒）。全量结果及日志见第七轮交付目录；此前第六轮的浏览器证据仅适用于其当时版本，本轮不将其写成新的浏览器验证。
