## 摘要

本研究计划书针对以下问题给出方案：一个已完成工程实现、但尚未开展科学验证的自适应学习系统，如何转化为计算机学科可发表的学术贡献，以及一篇完整的博士学位论文。本文首先盘点系统的六类可转化资产（最优难度引擎、知识追踪、游戏化机制集合、学习方法推荐、算法透明度与合规、倦怠预警），并逐项给出可申明贡献（C1–C7）与支撑该贡献所必需的证据。其次，本文明确界定本项目的科学问题边界：核心科学问题并非"如何提升知识追踪预测精度"（该赛道已被深度学习知识追踪基准主导），而是"在真实学习者身上，源自计算神经科学的 85% 最优学习规则是否成立，以及多类游戏化干预中何者对长期学习结果有效"。第三，本文给出三阶段研究设计（算法形式化与可复现性、观测性研究、随机化消融实验），并规定每一阶段的估计量、数据来源与效度威胁。第四，本文如实披露本项目的关键限制：当前系统尚无经伦理审查的真实学习者数据，685 个测试用例全部为单元测试，因此任何效果性主张在获得真实数据前均不可提出。本文的立场是：工程完成度不等于科学贡献，但可复现的工程资产是开展科学验证的必要前提；本项目当前已完成后者，前者尚待开展。

**关键词**：自适应学习系统；最优难度；知识追踪；游戏化；研究设计；可复现性；数字诚信

## 1. 研究背景与问题陈述

### 1.1 背景

自适应学习系统的核心承诺是：根据学习者的实时状态选择最有利于学习的题目与干预。这一承诺依赖两个尚未被充分验证的前提。其一，**难度选择的最优性准则**如何确定；其二，**维持参与度的干预机制**是否真正促进学习，而非仅仅提升使用时长。

关于第一个前提，一项被广泛引用的研究提出：当任务错误率约为 15%（即成功率约 85%）时，人工神经网络与一类计算神经科学模型的学习速率达到最大（[@wilson2019eightyfive]）。该结论在其原始语境（感知机与计算神经科学模型）中得到验证，但其作者明确指出，该结论如何推广到人类教育场景尚需进一步研究。这一"外部效度缺口"构成本研究的第一个科学机会。

关于第二个前提，游戏化学习的效果在不同研究中呈现显著异质性。元分析证据表明，效应量随具体元素与实现方式而波动，"游戏化"作为整体标签的解释力有限（[@sailer2017how]；[@sailer2020meta]）；针对具体元素的对照实验进一步显示效应依赖于实现质量（[@mazarakis2024whichone]），并有证据表明浅层游戏化的效应是短暂且有限的（[@lieberoth2015shallow]）。与此同时，部分游戏化设计已涉及剥夺用户自主性的"暗黑模式"（[@gray2018dark]）。因此，"哪些机制对长期学习结果有效、哪些无效甚至有害"构成本研究的第二个科学机会。

### 1.2 问题陈述

本研究处理的核心问题是：

> 在一个具备可解释难度适配引擎与大规模游戏化干预集合的真实学习系统中，（a）源于计算神经科学的最优错误率准则能否在人类学习者身上复现；（b）八类游戏化干预中，何者对长期学习结果具有可检出的因果效应；（c）当多个干预机制在同一决策点产生方向性冲突时，何种仲裁规则可在不违反健康与伦理约束的前提下维持系统的一致性。

### 1.3 研究问题

- **RQ1（外部效度）**：85% 最优错误率准则在人类学习者的多知识点练习场景中是否成立？若不成立，最优错误率的经验分布为何？
- **RQ2（因果效应）**：八类游戏化干预分别对长期学习结果与留存具有何种因果效应？效应是否存在类别间异质性？
- **RQ3（机制与边界）**：上述效应通过何种中介路径产生（作答量、间隔分布、心流通道停留时长）？效应在何种学习者子群中增强或反转？
- **RQ4（仲裁）**：在健康与伦理约束下，干预冲突的仲裁规则如何影响上述效应的估计？

### 1.4 研究范围与排除

明确排除以下方向，以避免资源分散与主张失焦：

1. **不以知识追踪预测精度为主赛道**。深度学习知识追踪已有系统性基准与综述（[@liu2025pykt]；[@abdelrahman2023knowledge]；[@preprints2025dlktreview]），以本项目所采用的贝叶斯知识追踪模型（[@corbett1994knowledge]）在该赛道竞争不具优势。
2. **不以通用大模型教育应用为主赛道**。该方向近期已有大量工作，且本系统当前不包含大模型推理链路。
3. **不以区块链教育数据存证为核心论文**。相关技术可行性已有研究（[@choudhary2025blockchain]；[@hepp2018originstamp]），但与本项目的核心科学问题关联薄弱，仅列为可选附录。

## 2. 文献基础与研究缺口

本节的详细论证见《LearnFlow 文献测绘与研究缺口报告》，此处仅给出与本研究问题直接相关的三条缺口陈述。

**缺口一（跨学科迁移未验证）**：最优错误率准则的提出与验证均在人工神经网络与计算神经科学模型内完成，其在人类学习者身上的外部效度未经验证（[@wilson2019eightyfive]）。

**缺口二（机制层面的因果证据稀缺）**：现有游戏化研究多以"游戏化 vs. 无游戏化"为处理变量，缺乏机制层面的消融证据；且已有自适应游戏化研究的样本量普遍偏小，限制了效应检出的可靠性（[@sailer2020meta]；[@mazarakis2024whichone]）。

**缺口三（学习分析的可复现性危机）**：学习分析领域长期面临指标定义漂移与数据质量问题，已有工作提出以标准化事件流与多源数据规范加以缓解（[@kitto2020xapi]；[@ieee9274xapi2023]；[@mangaroska2019multisource]）。本项目的可复现性基础设施（机制注册表指纹、落地扫描、计数印章）针对其中"系统自描述"这一子问题。

### 3.1 资产 A：四层融合最优难度引擎

`app/services/optimal_difficulty.py`（564 行）为系统的方法学核心，其结构为四层：

- **L1　85% 规则**：以目标错误率 $\text{ER}^* \approx 0.1587$（对应成功率 0.8413）为最优学习点，学习速率因子在 $\text{ER}^*$ 处取理论最大值；实现覆盖高斯、拉普拉斯、柯西三种噪声分布下的目标值（0.8413 / 0.8161 / 0.7500），并以 Winitzki 近似实现 $\text{erf}^{-1}$，避免对科学计算库的依赖（[@wilson2019eightyfive]）。
- **L2　FSRS 难度模型**：难度 $D \in [1, 10]$ 的记忆科学尺度，含回退参数的更新式。
- **L3　Elo 能力估计**：以自适应步长更新能力值，并通过量纲映射 $d_{\text{elo}} = 800 + \frac{d-1}{9} \times 1400$ 将难度尺度映射到能力尺度。
- **L4　心流通道**：将预期成功率映射为心流分区（无聊 / 心流 / 伸展 / 焦虑），并给出成功率到能力差的对数映射。

**该资产的关键可申明贡献在于跨层量纲映射**：L2 的记忆科学难度尺度与 L3 的竞技评分能力尺度原本不可通约，量纲映射使 85% 规则可直接作用于题目选择。该映射的合理性与可证伪性是本研究必须坚持论证的要点，其形式化见《LearnFlow 难度适配引擎 v2 设计》。

### 3.2 资产 B：贝叶斯知识追踪与冷启动特性

`app/services/knowledge_tracing.py`（217 行）实现标准贝叶斯知识追踪（[@corbett1994knowledge]），并在作答次数达到阈值后触发参数自适应。

**学术定位**：在深度学习知识追踪占据精度优势的背景下（[@liu2025pykt]），该资产的价值不在精度，而在**可解释性与数据稀疏条件下的冷启动表现**。近期综述指出该领域相当比例的研究未处理数据质量问题且过度依赖单一精度指标（[@preprints2025dlktreview]），这为"可解释模型在部署初期的比较优势"提供了可实证的研究空间。

### 3.3 资产 C：游戏化机制集合

系统的游戏化层由 9 个引擎文件构成，共 5,209 行。经预注册去重规则处理，唯一机制为 **54 个**（LF-M01–LF-M54），分属八类理论类别。**必须明确**：项目需求文档标题声称的 76 与其表格求和 69 均不可复算，论文主表述一律使用 54，并给出 52–57 的敏感性区间。（LF-M54 班级宠物共养为本轮新增，注册表指纹随机制增删变化。）

该资产的独特价值在于：54 个机制全部具备运行时开关与统一效应接口，使**机制层面的消融实验**在工程上成为可能；而已有自适应游戏化研究受限于样本量与实现方式，极少能在机制层面开展消融。分类学、形式化与仲裁机制详见《LearnFlow_机制治理与落实方案》。

### 3.4 资产 D：学习方法推荐与元学习技能树

学习方法层由统一注册表 `method_registry.py`（849 行）统辖 **28 种学习方法**（LF-L01–LF-L28），另有 16 个节点的元学习技能树（`meta_learning_skilltree.py`，481 行）。

**可申明贡献的方向**：学习策略推荐的形式化——基于知识状态与心流分区自动选择学习策略，并检验该推荐的增益。需注意：方法推荐的有效性本身是一个独立的因果问题，不应与难度适配的效应混同估计。

### 3.5 资产 E：算法透明度与合规框架

系统提供面向学习者的算法解释端点，内置 A/B 测试分流（`ab_test_framework.py`，779 行），并包含未成年人保护模块（`anti_addiction_compliance.py`，266 行）。

**可申明贡献的方向**：面向学习者的算法透明度设计及其对信任与持续使用的影响。该方向与教育人工智能的伦理与治理需求直接相关（[@solar2020standards]）。

**限制披露**：`anti_addiction_compliance.py` 中的未成年保护引擎当前**无任何调用方**（详见 §7 表 7-1）。在未接线前，不得以"系统具备未成年人保护机制"作为贡献陈述。

### 3.6 资产 F：风险监控与倦怠预警

`risk_monitor.py`（171 行）实现四级风险等级与三色分区，含 11 个阈值常量；当前阈值为未成年人防沉迷的时长上限与夜间宵禁。

**可申明贡献的方向**：学习倦怠的多指标早期预警（连续失败、跳过率、夜间使用、知识点重复）。该资产的证据强度最弱，宜作为探索性研究而非核心贡献。

## 5. 研究设计

本研究分三阶段推进，前一阶段是后一阶段的必要前提。

### 5.1 第一阶段：算法形式化与可复现性基础设施

**目标**：使系统的机制集合、算法参数与决策过程成为可复算、可审计的研究对象。

**内容**：
1. 机制注册表的建立与指纹化（已完成：54 个机制，指纹 `ee1a49be5732`）；
2. 统一效应接口与三层漏斗仲裁器（已完成）；
3. 运行时接线与落地扫描（已完成：53/53 落地，其中 34 个具编排器门控）；
4. 决策快照与埋点（已完成：`learning_events` + `decision_snapshot`）；
5. 计数印章与复算脚本（已完成：六项指标全部 `verified`）。

**产出**：系统论文（artifact paper）与可复现性附件。**该阶段不产出效果性主张。**

### 5.2 第二阶段：观测性研究

**目标**：在真实学习者数据上刻画最优错误率的经验分布与心流通道的停留模式，为第三阶段的假设生成提供依据。

**估计量**：描述性估计量（最优错误率的分布、心流分区停留比例、留存曲线），不涉及因果推断。

**数据来源**：经伦理审查的平台日志，来源为本系统的 `learning_events` 埋点。

**效度威胁**：观测数据存在选择偏差（学习者自选题目、自选退出），因此本阶段结论仅可用于假设生成，**不可用于因果主张**。

### 5.3 第三阶段：随机化消融实验

**目标**：估计八类游戏化干预与难度策略的因果效应。

**设计要点**：
- **随机化单位**：学习者（个体），嵌套于班级，故需考虑聚类相关；
- **设计效应**：$\text{DEFF} = 1 + (m-1)\rho$，取 $m = 30$、$\rho = 0.05$，得 $\text{DEFF} = 2.45$；
- **多重检验**：分层 Gatekeeping（Gate 0 全局 omnibus，α = 0.05 → Gate 1 八类 Holm 校正，α′ = 0.00625 → Gate 2 机制级 → Gate 2.5 预注册交互，α′ ≈ 0.0167）；
- **样本量**：在 α = 0.00625、功效 0.8、$d = 0.3$ 条件下每组约 428 人（复算：`scripts/power_table.py`）；
- **估计量**：意向治疗效应（ITT），$\tau_c = \mathbb{E}[Y_i(0)] - \mathbb{E}[Y_i(1)]$；
- **预注册**：`scripts/prereg/ablation_design_v1.yaml`。

**伦理约束**：未成年人不参与动机类机制的关闭实验；学习成瘾指数高风险个体被排除；健康护栏类（H 类）机制在所有条件下恒开。

| 机制可独立开关 | 机制注册表 + `is_enabled` 门控 + 类别级关闭（`--off-category`） | 已具备（34 个机制具编排器门控） |
| 处理分配可记录 | A/B 框架的分流与落库 | 已具备（JSON 后端；SQL 后端未实现） |
| 结局可观测 | `learning_events` + `decision_snapshot` 埋点 | 已具备 |

### 6.2 数据获取的可行性

本项目的关键瓶颈不是工程，而是**真实学习者数据**。可行路径有三条，按可行性排序：

1. **合作学校部署**：与学校或教育机构合作部署，取得伦理审查与知情同意；
2. **公开数据集复现**：在公开的大规模学习日志数据集上复现本系统的算法，检验算法层面的主张（不涉及本系统自身的干预机制）；
3. **模拟研究的正确定位**：模拟只能用于检验算法的统计性质（如量纲映射的一致性、估计量的有限样本性质），**不可用于检验任何关于人类学习行为的主张**。

### 6.3 与现有基准的关系

在系统与算法层面，已有若干公开编程练习数据集可用于算法比较（[@codeworkout2021]；[@falconcode2022]；[@kcgenkt2025]），可作为算法阶段的外部验证数据来源。

## 10. 伦理与数据治理

1. **知情同意**：所有数据收集须取得学习者及其监护人（未成年人）的知情同意；
2. **数据最小化**：仅收集研究必需字段；决策快照须脱敏后用于分析；
3. **退出权**：学习者可随时退出，退出后数据不纳入分析；
4. **未成年人保护**：健康护栏机制恒开，不参与消融；
5. **算法透明度**：向学习者提供难度与干预决策的解释端点；
6. **负面结果发布**：无论结果是否支持假设，均按预注册方案报告。
