## 摘要

本文对一个自适应学习系统（LearnFlow，后端 20,349 行 Python、41 个服务模块、67 个源文件、72 个 API 端点、685 项测试）的研究资产进行系统审计，提出由七项候选工作构成的期刊投稿组合，并对每一项作五维新颖性评分与抗模式坍缩检查。审计的三项主要结论如下。

**第一，组合的实际规模为五项核心工作加一项系统 artifact，一项建议终止。** 六项核心候选的五维新颖性总分区间为 11–22（满分 25）。其中两项（P2、P4）总分 ≥ 20 且依赖度为零，构成组合的锚点；一项（P6，区块链教育数据可信处理）总分 11，命中"技术寻求问题"型抗模式，建议终止，其真实需求（日志防篡改与可审计）由 P4 的可审计干预账本以低两个数量级的成本吸收。

**第二，项目的历史数字不实问题已从"风险"转化为"方法学资产"。** 项目文档曾声称"76 个游戏化机制"，而四层计数口径复核给出：L0 层 `*Engine` 类 81 个（含类别错误，把知识追踪、难度动态调整、间隔重复等学习科学算法计入）、L1 层实现单元 60 个、L2 层语义去重后唯一机制 **53** 个（已编号 LF-M01…LF-M53）、PRD 自身表格逐项求和 69 个。差额 23 = 76 − 53 可分解为 7（PRD 标题无据虚高）+ 9（表格混入非机制条目）+ 7（跨引擎重复实现）。本文建议的处理不是隐藏该差异，而是将其作为所提机制注册表方法的首次应用实例写入 P4，并随稿提交可复算脚本。

**第三，"零自有部署数据"不构成发表障碍，但要求重写方法学身份。** 六项工作中有四项（P1/P2/P3/P5）可完全依托公开学习者日志与离策略评估完成，一项（P4）的 E1–E3 实验为静态分析。唯一需要人类被试的是 P4 的 E4 实验；依本项目功效分析脚本实测（聚类规模 m=30、功效 0.8、α=0.05、ICC=0.05），即便只测近端感知指标亦需每臂 154–241 人，而非早期估计的 60–120 人。

**关键词**：自适应学习系统；难度测量；85% 规则；序贯决策；游戏化干预治理；研究资产审计；投稿组合规划

# 0. 引言

## 0.1 本文档的定位与边界

本文是**研究规划文档**，不是研究论文。因此本文允许出现尚未执行的判断、尚未验证的假设与明确标注为"待核验"的外部事实；但本文**不允许出现无法由仓库内可复算脚本验证的自身资产数字**。凡涉及 LearnFlow 自身的规模、机制数、方法数、测试数、接线状态，一律以 `learnflow-backend/scripts/` 下的脚本输出为准，并在 §2 给出复算命令。

本文不覆盖以下内容：各论文的具体写作与实验执行（见 `LearnFlow_博士毕业论文总纲.md`）；机制注册表与仲裁器的工程细节（见 `LearnFlow_机制治理与落实方案.md`）；逐项文献综述（见 `LearnFlow_文献测绘与研究缺口.md`）。

## 0.2 审计方法

审计沿四条路径展开。

1. **资产路径**——对后端源码作静态清点，产出可复算的规模与机制台账（§2）。
2. **新颖性路径**——对每项候选工作作五维评分：问题新颖性、方法新颖性、结果新颖性、数据与系统新颖性、理论贡献，各维 1–5 分。
3. **抗模式路径**——对每项候选工作检查六个已知失效模式：技术寻求问题（含"区块链 + X"、"LLM + X"）、系统论文陷阱、消融实验陷阱、无数据陷阱、数字膨胀陷阱、以及该项特有的其他陷阱。
4. **可行性与依赖路径**——评估资源约束下的现实性，并刻画候选工作之间的依赖性质与传导风险。

## 2.3 接线强度的两个层次（须在稿件中区分）

`landed` 指标的判定式为 `impl_ref 可达 OR 编排器接线/门控`（见 `scan_mechanism_landing.py:177`）。这是一个**可达性下界**，不等于"该机制已在生产路径上被真实调用"。逐层分解如下。

| 层次 | 数量 | 含义 |
|---|---:|---|
| 编排器步骤映射成员（`PIPELINE_MECHANISM_MAP`） | **34** | 机制键显式登记于编排流程的某一处理步骤 |
| 其中：另有独立 `is_enabled("<key>")` 门控语句并真实调用引擎函数 | **31** | 门控关闭时该机制效果被真实抑制，消融对照成立 |
| 其中：仅有步骤映射、无独立门控语句 | **3** | `lai_downgrade` / `forced_rest` / `minor_protection`——健康合规护栏，按设计豁免于消融门控 |
| **仅凭 `impl_ref` 可达性计入、未进入编排器步骤映射** | **19** | 有可定位实现，但未在 `process_submission` 主链路上被调度 |

**稿件表述纪律**：不得将 53 个机制一律描述为"已在生产链路上调用"。正确表述为"53 个机制全部登记入统一注册表且具备可定位实现；其中 34 个进入编排器步骤映射，31 个具备独立的运行时开关与真实引擎调用"。

# 4. 论文卡片

## 4.1 【P1】难度量纲的可公度性

### (a) 论文卡片

**暂定标题**

- 中文：《自适应学习系统中难度量纲的可公度性：统一知识追踪、间隔重复与竞技评分的测量框架》
- 英文：*On the Commensurability of Difficulty Scales in Adaptive Learning: A Unified Measurement Framework Bridging Knowledge Tracing, Spaced Repetition, and Competitive Rating*

**研究问题**

当一个自适应系统同时持有知识追踪掌握度、间隔重复记忆难度、竞技评分能力估计、窗口成功率这四个"难度/能力"量时，它们是否可以被置于同一个可校准、可逆、且在单调仿射变换下稳定的量纲之上？

**核心贡献**

- **C1 — 不公度性的形式化刻画与不稳定性命题。**
  论证当前编排器的线性加权融合 `0.45·BKT + 0.35·DDA + 0.20·optimal` 在测量论意义下**不是良定义的**：知识追踪侧为有界潜变量的整数化（顺序量级）、窗口成功率侧为比率量级且是结果而非难度、最优难度侧为浮点近似区间量级。三者量纲类型不同，线性组合结果随任一侧的单调仿射重参数化而漂移。
  → **可验证命题**：将知识追踪侧由 `mastery×9+1` 改为 `mastery`（即除以 9 再减 1/9），最优权重将由 0.45/0.35/0.20 变为显著不同的有效权重；而统一量纲方法的输出**不变**。该差值可精确测量。

- **C2 — 统一难度量纲（UDS）及其可逆映射。**
  以"在给定学生能力 θ 下正确作答该题的对数几率"为公共货币，构造可逆映射：
  - 竞技评分 θ → 本身即对数几率尺度（评分定义即 400·log₁₀ 赔率），天然为区间尺度；
  - 掌握度 m → `logit(m)`，须以 Jeffreys 先验处理 m→0/1 的边界；
  - 记忆难度 D ∈ [1,10] → 经可提取性公式 `R(t) = (1 + F·t/S)^(−C)` 反解"该题对该生的有效成功率"，再取 logit；
  - 窗口成功率 r → **不是难度，而是难度与能力的联合结果**，须以 `difficulty = θ − logit(r)` 分离（此即 C1 所指的范畴错误）。
  → 统一后给出标定算法：在共享题目集上以 Platt scaling 或层级 IRT 联合估计各源到 UDS 的映射参数与置信权重（权重由各源的校准误差反推，而非硬编码）。

- **C3 — 目标命中率的实证对比。**
  在公开数据上比较三种方案的"85% 目标命中率"（被选题目的实测成功率落在 [0.80, 0.90] 区间的比例）：(i) 现有线性融合 + 精确等值匹配；(ii) 统一量纲 + 等值匹配；(iii) 统一量纲 + 区间匹配 + 置信度加权。并报告**仿射变换稳定性**（在五种单调重参数化下输出排序的 Kendall τ 漂移）。

**技术资产依据**

- `app/services/optimal_difficulty.py`（564 行）：85% 规则层 / 记忆难度映射层 / 能力估计层 / 心流通道层
- `app/services/knowledge_tracing.py`（217 行，BKT，参数未标定）
- `app/services/dda.py`（170 行，窗口成功率 → 1–10）
- 已知缺陷：融合权重硬编码且无标定程序；模型输出中 4/5 被丢弃（仅取标量）；前端难度带边界硬编码

**方法路线**

1. **测量论论证**（纯理论）：以 Stevens 量表分类与表示论刻画四个源的量纲类型，给出良定义性判据。
2. **标定实验**（公开数据）：在共享题目集上拟合各源 → UDS 的映射，以留出交互评估校准误差（可靠性图、Brier 分数、期望校准误差 ECE）。
3. **不稳定性实验**（公开数据 + 合成重参数化）：量化线性融合的权重漂移。

## 4.2 【P2】85% 规则的外部效度检验

### (a) 论文卡片

**暂定标题**

- 中文：《85% 规则在真实学习者身上成立吗？——基于百万级学习交互日志的最优错误率离策略评估》
- 英文：*Does the Eighty Five Percent Rule Hold for Human Learners? An Off-Policy Evaluation of Optimal Error Rate on Million-Scale Interaction Logs*

**研究问题**

Wilson 等 (2019) `wilson2019eightyfive` 在梯度下降类学习者的二分类任务上推导出的 15.87% 最优错误率，在真实人类学习者的多知识点、含遗忘、含提示与跳过的学习场景中是否成立？若不成立，其剂量—反应曲线的形状与最优错误率位于何处？

**为什么这是第一优先**

1. **问题由原作者本人标示**（F2）。Wilson 明确指出该规则"可能不直接适用于学生"，因为学生并非在学习二分类任务。这不是从文献缝隙中挖掘的缺口。
2. **验证域极窄**（F1）：二分类、无提示、无跳过、无遗忘、无多知识点迁移；真实学习场景五条全不满足。
3. **结果无论正负均构成贡献**：成立 = 首次大规模人类验证；不成立 = 对一个高引理论的干净修正。**配合预注册，阴性结果亦可发表**——这是博士生可获得的最优风险结构。
4. **零依赖、零自有用户**：三个公开数据集，千万级交互。
5. **规模优势可正面陈述**：对照 F7/F8（该领域多数研究 n=7–252），本研究的样本量高出四至五个数量级。

**核心贡献**

- **C1 — 大规模离策略剂量—反应估计。** 以 IRT 事前错误率为剂量变量，以掌握速度等为结局，在三个公开数据集上估计剂量—反应曲线，并报告最优错误率 ê\* 的置信区间。
- **C2 — 五个前提条件的逐项检验。** 分别对二分类、无提示、无跳过、无遗忘、无迁移五个前提作分层分析，量化每一条被违反时的效应衰减。
- **C3 — 与理论预测值的形式对比。** 将 ê\* 与 15.87% 作统计检验，并按学科、知识点数、学习者能力分层报告异质性。

**识别策略要点**

- **IRT 事前错误率**：以全样本拟合 IRT（item-split 交叉拟合防泄漏），计算作答前可知的预测正确率 `p̂ᵢⱼ = σ(θᵢ − βⱼ)`，事前错误率 `eᵢⱼ = 1 − p̂ᵢⱼ`。该量在给定 (θᵢ, βⱼ) 下与本次作答的随机扰动独立，可用于剂量—反应估计。
- **双重稳健离策略评估（DR / AIPW）**：在无在线 A/B 的条件下估计反事实策略效果；只要倾向模型或结果模型之一正确，估计即一致。
- **必备稳健性程序**：权重截断、报告有效样本量、阴性对照结局、E-value 敏感性分析。

- **理论检验类工作的"已知答案"偏见**（中）。**缓解**：预注册必须在接触数据前完成（OSF / AsPredicted），并明确声明阴性结果同样构成贡献。

## 4.3 【P3】有序动作 Bandit 与心流通道的形式化

### (a) 论文卡片

**暂定标题**

- 中文：《有序动作空间上的难度选择：带遗忘状态的心流通道序贯决策形式化》
- 英文：*Ordinal-Action Bandits for Difficulty Selection: Formalizing the Flow Channel with Memory-State Dynamics*

**研究问题**

若把难度选择形式化为**动作空间有序、奖励是学习增益（而非正确率）、状态含记忆衰减**的序贯决策问题，能否得到比"贪心 + 精确等值匹配"更强的理论保证与实证表现？

**核心贡献**

- **C1 — 有序动作空间的形式化与遗憾界适配。**
  现有实现把难度当作独立动作（以精确等值匹配筛选题目），等价于假设不同难度档的期望奖励互不相关。事实上难度是有序的：相邻难度档的期望学习增益满足 Lipschitz 连续性（|μ(d) − μ(d+δ)| ≤ L·δ）。
  → 因此可用连续臂 / Lipschitz bandit（Zooming algorithm、HOO；参见 `neurips2017posetbandits`）替代独立动作 UCB / Thompson Sampling，将遗憾界由独立动作的 `Õ(√(K·T))` 改进到有序动作的 `Õ(T^{(d̄+1)/(d̄+2)})`（一维动作下约为 `Õ(T^{2/3})`），并给出 Lipschitz 常数 L 的**从数据估计方法**。
  → **这直接回答了"为什么精确等值匹配是错误的建模"**：它丢弃了相邻难度档之间的信息借用，在样本稀缺的冷启动期代价最大。
  → **诚实标注**：这是**已有理论的适配**，不是新证明。价值在于证明"难度选择问题满足该理论的前提假设"，并给出 L 的可估计算法。

- **C2 — 心流通道的二维可标定形式化。**
  把心流通道从一维正确率区间升级为二维区域：维度一为**事前错误率**（能力—难度匹配）；维度二为**努力/时间代价**（反应时 z 分数、提示使用次数、放弃率）。
  → 给出边界标定算法：以 P2 的剂量—反应曲线定错误率方向的边界（**直接消费 P2 的结果**），以反应时分布的分位数定时间方向的边界。
  → 输出一个**可证伪的命题**：心流区应定义为"学习增益 > 阈值 且 努力代价 < 阈值"的帕累托前沿，而非固定的 [0.75, 0.85] 区间。相关背景见 `sensors2026flowbalance`。

- **C3 — 遗忘作为状态转移：把记忆可提取性接入序贯决策。**
  定义状态 `s = (θ, {R_k(t)}_k)`，其中 `R_k(t)` 是知识点 k 在时刻 t 的可提取性。同一道题在不同的 `R_k(t)` 下对同一学生具有**不同的有效难度**。
  → 动作价值函数变为 `Q(s, d)`，选题策略 `π(s)`。这是把记忆科学真正接入决策的关键一步，也是 **P1 统一量纲的下游消费者**（动作空间 d 的度量由 P1 定义）。
  → 给出在可提取性单调衰减下的结构性性质（如最优动作随时间的单调漂移）与可检验预测。

**方法路线**

1. **理论**：证明难度选择满足 Lipschitz 条件；推导有序动作遗憾界；给出 L 的估计器。
2. **模拟器构建**：以 **P2 校准出的剂量—反应曲线 + IRT 参数 + 记忆模型**构建学习者模拟器。**这是本篇能否成立的关键。**
3. **模拟器验证（不可省略）**：以留出数据检验模拟器的预测误差（下一题正确率分布、掌握速度分布、反应时分布）。**若模拟器误差过大，必须诚实报告并相应下调结论置信度。**
4. **离策略评估**：在真实日志上以 IPS / DR 评估所学策略与基线策略的累积学习增益。

**实验设计概要**

- **数据集**：同 P2，加 P2 产出的模拟器
- **基线**：(i) 现有贪心精确等值匹配；(ii) 窗口成功率固定步长；(iii) ε-greedy 独立动作；(iv) UCB / Thompson Sampling 独立动作（10 档）；(v) 本文方法：Lipschitz / Zooming bandit，有序动作 + 记忆状态
- **评价指标**：累积学习增益（离策略估计 + 模拟器内）；遗憾；心流区内停留比例；掌握所需作答次数；冷启动期（前 20 次交互）的表现差异
- **预期效应量**：**小到中等（d ≈ 0.15–0.35）**，冷启动期更大。**须诚实警告：现有系统"基本可用"，不应期待数量级提升。** 本文卖点应为**理论保证 + 冷启动改善**。

## 4.4 【P4】游戏化干预的形式化与冲突仲裁

### (a) 论文卡片

**暂定标题**

- 中文：《从临时引擎到可仲裁的干预单元：游戏化干预的形式化注册表、冲突检测与预算分配》
- 英文：*From Ad-Hoc Engines to Arbitrable Intervention Units: A Formal Registry, Conflict Detection, and Budget Allocation Model for Gamified Learning Systems*

**研究问题**

当一个学习系统里同时存在数十个行为干预机制、其中若干**语义直接对立**（催促加时、未成年人时长限制、劝退休息），如何形式化地建模干预空间、**自动检测冲突**，并在**有限干预预算**下分配？

**为什么这是第二优先**

1. **这是组合中唯一一项"只有本项目能写"的工作。** 其他系统的游戏化机制通常为 3–8 个，根本暴露不出"多干预机制共存冲突"这一问题。本项目拥有 53 个已登记机制、三处语义直接对立的干预（错失恐惧提示 vs 未成年保护 vs 休息提醒）。这些在工程意义上是缺陷，在研究意义上是**独一无二的观察场**。
2. **它把数字不实问题转化为方法学资产。** 见 §4.4(b) 的说明。
3. **它绕开了自适应游戏化领域最大的陷阱**（F7/F8）：不作单机制消融，也不声称任何机制对学习有效。

**核心贡献**

- **C1 — 干预的元组形式化（Intervention Schema）。**
  定义 `Intervention = ⟨trigger, target_construct, direction, channel, cost, side_effect, precedence⟩`：`trigger` 为触发条件；`target_construct` 为作用构念（参与度 / 坚持性 / 自我效能 / 社交联结 / 时长）；`direction` 为促进或抑制（**冲突检测的关键字段**）；`channel` 为呈现通道；`cost` 为干预预算消耗；`side_effect` 为已知副作用集合；`precedence` 为合规优先级。
  → 把本项目 53 个机制全部映射到该 schema，报告**映射覆盖率**。预期会有 10–20% 的机制因语义模糊无法归类，**这个"不可归类的部分"本身是一个发现**。
  → **与既有文献的关系**：Hexad 用户类型与自适应游戏化综述只做"用户类型 → 元素偏好"的**静态匹配**（参见 `sailer2017how`、`sailer2020meta`），缺乏"干预作为可调度、可冲突、有预算的资源"的形式化。此即本贡献的定位。

- **C2 — 三类冲突的自动检测。**
  - **类型 I · 语义对消**：`target_construct` 相同但 `direction` 相反，且触发窗口重叠。**本项目实**：错失恐惧提示（目标=时长，方向=促进）vs 未成年保护（目标=时长，方向=抑制，合规强制）vs 休息提醒（目标=时长，方向=抑制）。一个系统内同时运行互相抵消的行为干预，是一个可直接发表的结构性观察。
  - **类型 II · 通道竞争**：同一 `channel` 在同一时间窗内被多个干预争用。
  - **类型 III · 目标冲突**：短期参与度、长期学习与合规约束之间的多目标冲突（形式化为 Pareto 冲突检测）。
  → 给出检测算法与复杂度分析，并在本项目上报告检出结果。

- **C3 — 干预预算与约束分配。**
  每个会话/每日的干预次数上限（防骚扰与防习惯化）。形式化为**带预算约束的序贯分配问题**，可归约到预算化多臂老虎机或多选择背包。
  → 给出近似算法与**遗憾分析**（这是本篇冲击 CCF-B 以上的理论筹码）。
  → 给出合规硬约束（未成年时长限制）的**优先级抢占语义**证明：在高优先级约束激活时，低优先级干预必须静默——这是一个**可验证的系统性质**，可写为命题并作模型检验。本项目已在编排器中对三处健康合规护栏作了门控豁免设计，可作为该性质的实现实例。

- **C4 — 可审计的干预账本（Intervention Ledger）。**
  把"干预状态不可审计"抽象为一个研究问题。
  → 设计只追加的账本 schema（含 `mechanism_id`、`intervention_instance_id`、`budget_consumed`、`arbitration_decision`、`preempted_by`），并给出**一致性检查算法**（可检出"预算超支"、"被抢占却仍执行"、"决策无记录"三类违规）。
  → **本项目的地基已部分就位**：`learning_events` 事件流表已实现 `decision_snapshot` 冻结机制开关与仲裁结果；但 `budget_consumed` 与 `preempted_by` 字段尚未实现，须在论文的实现章节如实标注为待完成项。
  → **该账本同时是 P6 的替代方案**：以 Merkle 树 + 周期性公开锚定即可获得防篡改与可审计性，**不需要任何区块链**（参见 `hepp2018originstamp`）。

**技术资产依据**

- 53 个唯一机制，全部登记于 `mechanism_registry.py`（597 行）；成熟度分布为完整 8 / 部分 37 / 占位 8
- 编排器接线强度：34 个进入步骤映射，其中 31 个具备独立运行时开关（详见 §2.3）

- 实验基础设施：`ab_test_framework.py`（779 行）支持机制级与类别级开关、设计效应与样本量门槛、注册表指纹

**方法路线**

1. **Schema 构造**（理论）：从游戏化与行为改变理论（Hexad、自我决定论、MDA 框架、Fogg 行为模型、COM-B）导出 schema 字段并论证完备性。

## 4.5 【P5】LLM 难度标注的可靠性边界

### (a) 论文卡片

**暂定标题**

- 中文：《机器共识不是人类难度：面向自适应学习的大语言模型题目难度标注审计》
- 英文：*Machine Consensus Is Not Human Difficulty: Auditing LLM-Based Item Difficulty Annotation Against Adaptive-Learning Ground Truth*

**研究问题**

当 LLM 被用作"离线难度标注 → 在线自适应决策"的先验时，LLM 标注的难度与**真实学习者感知的难度**一致性有多高？在什么条件下这个先验会**损害**（而非改善）自适应系统的决策？

**为什么这不是又一个"LLM + X"**

v2 规划中明确写入"LLM 离线标注 + 在线决策"。而依 F5，**这个前提在学界尚无共识，且存在直接矛盾的两派**：乐观派报与人类标注 Pearson r ≈ 0.80–0.82；悲观派在 20+ 模型 × 4 领域的研究中报 Spearman ρ < 0.5，并发现模型规模越大越不对齐、模型收敛于"机器共识"而非人类难度。

**因此本篇的定位是"审计与边界条件"，而非"我们用 LLM 做了标注"。这个定位决定了它是否是真论文。** 相关背景见 `raihan2025llmcsed`。

**核心贡献**

- **C1 — 以真实学习者响应校准的 IRT 难度为真值的大规模对齐审计。**
  设计：`N` 个模型（覆盖开源/闭源、大/小、通用/数学专用）× `K` 个学科 × `M` 道题。
  - **真值**：**不是**专家打分，**而是**用真实学习者响应数据经 IRT 标定出的难度 βⱼ（这正是自适应系统所需要的量）。
  - **测量**：Pearson r、Spearman ρ、二次加权 Kappa（按难度分位分箱）、以及系统性偏移方向。
  - **误差分解**：按学科 × 题型 × 难度分位 × 模型规模 × 提示策略（零样本 / 思维链 / 给出学生画像 / 成对比较）分解。
  → 输出一张"在哪些格子里 LLM 标注可用、在哪些里不可用"的**边界地图**。

- **C2 — "机器共识陷阱"的量化与证伪。**
  悲观派观察到模型收敛于机器共识，但**未给出可操作判据**。
  → 贡献：精确测量**模型间一致性**与**模型—人类一致性**，并检验前者是否显著高于后者。
  → **关键的可操作结论**：若成立，则意味着"用多模型投票/集成提高难度标注置信度"这一常见做法在该任务上是错误的——集成会提高模型的相互一致性，却不提高与人类的一致性，反而**放大**系统性偏差。
  → 给出判据：当 `ρ(inter-model) − ρ(model-human) > δ` 时，集成策略应当被禁用。**这是一个直接可执行的工程判据，且与乐观派方法（成对比较 + Bradley-Terry 本质上也是一种聚合）形成正面学术对话。**

- **C3 — 决策层面的影响评估：先验偏差 → 学习增益损失。**
  这是本篇**从"又一个相关性研究"升级为"CS 论文"的关键一步**。
  → 把 LLM 先验接入 **P3 的序贯决策框架**，作离策略/模拟器评估，量化 `先验偏差 δ ⇒ 累积学习增益损失 Δ(δ)`。
  → 输出一条**敏感度曲线**，并给出"何时该用 / 不该用 LLM 先验"的可操作阈值。
  → 该贡献直接决定 v2 架构是否成立，具有实际工程价值。

- **C4 — 层级贝叶斯校准：用少量在线响应压过有偏先验。**
  提出 `LLM 先验 → IRT 后验` 的层级校准模型，回答工程上真正关心的问题：**"需要多少条真实在线作答，才能把有偏的 LLM 先验纠正到可用的精度？"**
  → 通过模拟与公开数据验证给出 N\* 的估计与置信区间。

**技术资产依据**

- **依赖**：P1（统一量纲作为难度的公共载体）+ P3（下游决策框架）

**实验设计概要**

## 4.6 【P6】区块链教育大数据可信处理 —— 建议终止

### (a) 论证（替代原论文卡片）

**建议：终止该项工作。**

依据 F9，原方案"基于区块链的教育大数据可信处理模块"是**教科书级的"技术寻求问题"**：

1. **领域已呈提案饱和**。Choudhury 等（`choudhary2025blockchain`）以 PRISMA 评估 **150 个模型，其中 124 个已是原型/试点/完整实现**，结论原文为 "an avalanche of proposals"，并指出"可扩展性问题、整体性能不佳与成本上升是主要局限"。
2. **收益不明已被本领域自身综述承认**："在某些情况下，分布式账本方案是否优于更传统的中心化账本尚不清楚"（`razzaq2026blockchain`）。
3. **四大结构性障碍**（`isiaku2025barriers`）：可扩展性三难、监管模糊（GDPR 删除权与不可篡改之间是**法律层面的硬冲突**，非工程可解）、采用就绪度与技能缺口、术语不成熟。
4. **领域已转向 W3C 可验证凭证与去中心化标识符**，且共识路径为"法律承认 + 标准合规 + 小规模试点"（`jusic2025microcredential`）——**这在个人博士项目（无经费、无机构授权、无法律承认）的资源约束下不可达**。
5. **与研究主线正交**：它不回答任何关于"学习如何发生"或"系统如何决策"的问题，会稀释故事线。

**最根本的反对理由**：在**零真实用户数据、零机构参与、零法律承认**的条件下研究"教育大数据可信处理"，**命题本身不成立**——没有数据，何来处理？

## 4.7 【P7】系统论文：降级为 artifact，不计入核心论文

**结论：不撰写独立的"LearnFlow 系统期刊论文"。**

**理由**：组合中唯一会完全命中系统论文陷阱的形态就是它。典型拒稿理由为："This is an engineering report, not a research paper. The authors describe a system they built but do not answer a research question."

**替代做法（三步）**

1. **投一篇 6–8 页的系统描述短文**到 **JOSS**（Journal of Open Source Software）或 **SoftwareX**（Elsevier，非 CCF，SCI Q3–Q4）。目的不是学术贡献，而是：为 P1–P5 提供**可引用的 artifact**（审稿人要求复现时可指向它）；为博士论文的系统实现章节提供发表背书；周期短（JOSS 通常 1–3 个月）。
2. **开源 release + 完整 artifact**：代码、全部统计脚本（尤其是机制计数与落地扫描脚本）、数据集索引、Docker 镜像。
3. **在博士论文本体中撰写完整的系统章节**（这是学位论文的合法位置，期刊不是）。

**位置**：在 P1 与 P4 之后（需要有可展示的成果时），不占用投稿序列的关键路径。

**数字诚信要求**：即便在 JOSS/SoftwareX 短文中，也**必须**使用 53 而非 76。软件论文同样会被核验。

# 6. 博士论文的故事线

## 6.1 统一研究叙事

> 过去二十年，自适应学习系统的研究把几乎全部精力投在"把学生答对下一题的预测做得更准"上——pyKT 以 21 个深度模型 × 9 个数据集把这条路走到了尽头，却发现模型之间"分歧极小"、AUC 报告互相矛盾。
> 但一个更根本的问题从未被问过：这些系统所共同依赖的那个核心量——**难度**——究竟是不是一个被良好定义的可测量对象？
> 在一个真实的、有 53 个行为干预机制的 K12 平台上，我们看到了答案的样子：三套来源不同、量纲互不相容的"难度"被一个没有任何实证依据的硬编码权重（0.45/0.35/0.20）线性相加；相加的结果被用作一次精确等值匹配去筛选题目；而这个匹配所服务的目标值 85%，来自一篇只在人工神经网络与动物学习的二分类任务上验证过、作者本人明确表示"可能不适用于学生"的论文。
> 本论文论证：自适应学习系统的核心失败，不在于预测不够准，而在于**难度这个被所有组件共享的核心量，从未被当作一个可测量、可校准、可决策、可治理的形式对象来对待**。
> 我们因此做了五件事：为它建立测量论（P1）；检验它的目标值是否成立（P2）；把它嵌入序贯决策（P3）；审计替代性先验的质量边界（P5）；以及最后——当系统里有数十个基于它做出来的、互相冲突的行为干预时——为它们建立形式化与仲裁（P4）。

## 6.2 论点陈述（Thesis Statement）

> **自适应学习系统的核心失败不在于预测不够准确，而在于"难度"这个被所有组件共享的核心量从未被当作一个可测量、可校准、可决策、可治理的形式对象；本文通过建立难度的统一测量理论、以大规模真实学习者日志检验其最优目标值的外部效度、将其嵌入带记忆状态的序贯决策框架、并为由它派生的行为干预建立形式化治理，使自适应学习从"参数拼接的工程"转变为"可审计的测量与决策科学"。**

**一句话版**：把自适应学习系统中的"难度"从工程参数提升为可测量、可校准、可决策、可治理的一等公民。

## 6.3 学科定位

| 层次 | 归属 | 说明 |
|---|---|---|
| **主锚点 · 方法论身份** | **教育数据挖掘 / 学习分析** | P1/P2/P5 的方法核心是心理测量学 + 因果推断 + 大规模日志分析。这是最诚实的方法论身份 |
| **主锚点 · CCF 分类** | **数据库 / 数据挖掘 / 内容检索** | 投稿的 CCF 分区主要落在这里（TKDE / KAIS / IPM / Information Sciences）。**这是最现实的 CCF 归属** |
| **次锚点 · CCF 分类** | **人机交互与普适计算（用户建模与自适应交互）** | P4 的归属（UMUAI / IJHCS / TOCHI / CSCW） |

# 7. 关键战略判断

## 7.1 最锋利的两项新颖性

**第一锋利：P2 —— 85% 规则在真实学习者身上的大规模外部效度检验。**

判定依据：(1) 问题由 *Nature Communications* 作者本人划界（F2），非本研究挖掘；(2) 验证域极窄（F1），真实学习场景五条前提全不满足；(3) 结果无论正负均构成贡献，配合预注册，阴性结果亦可发表——这是博士生能获得的最优风险结构；(4) 零依赖、零自有用户；(5) 样本量较该领域现有研究（F7/F8，n=7–252）高出四至五个数量级，该对比本身即可写入引言。

**若只能保留一项，保留 P2。**

**第二锋利：P4 —— 多干预机制的冲突检测与预算仲裁。**

判定依据：(1) 组合中唯一一项他人做不了的工作（其他系统机制过少，暴露不出该问题），护城河最深；(2) 把项目历史数字不实问题转化为最强的可信度担保；(3) 错失恐惧提示、未成年保护、休息提醒三方语义对立是一个可直接发表的结构性观察；(4) 绕开了该领域最大的陷阱（单机制消融与效果声称）；(5) 零依赖，与其他工作无传导风险。

**两者的互补性**：P2 向外检验一个经典理论，提供**学术合法性**；P4 向内形式化一个工程现实，提供**独占性资产**。一项给出高度，一项给出独有性。

## 7.3 "零自有部署数据"的约束与破解

**核心判断：这不是"能不能发论文"的问题，而是"必须重写方法学身份"的问题。**

### 三类数据的严格区分与措辞纪律

| 类别 | 是否有 | 能否用于论文 | 稿件中的精确措辞 |
|---|---|---|---|
| ① 公开真实学习者数据 | 有（ASSISTments / EdNet / Junyi / 复习日志） | **完全可以** | "real learner interaction data from publicly available datasets (N = X)" |
| ② 自有系统的真实部署数据 | **0 行** | **不能** | **绝对禁止**出现 "our deployment data"、"real users of our system"、"in-the-wild evaluation" |
| ③ 自有系统的静态可分析资产（代码、机制清单、架构） | 有（20,349 行、53 个机制） | 可以，**但只能用于静态分析类研究** | "static analysis of a production-scale gamified learning platform (20,349 LOC, 53 registered mechanisms)" |

**措辞纪律**："real learner data"（真实学习者数据）不等于 "our deployment data"（我们的部署数据）。前者有（公开、千万级），后者没有。稿件中只使用前者，且措辞须精确到使审稿人无法误解。

### 各篇的数据需求

| 论文 | 数据需求 | 是否需要自有用户 | 关键技术 |
|---|---|---|---|
| **P1** | 公开学习者日志 + 复习日志 | 完全不需要 | 标定实验 + 合成重参数化 + 离策略回放 |
| **P2** | 公开学习者日志（3 个数据集） | 完全不需要 | **IRT 事前错误率 + 双重稳健离策略评估** |
| **P3** | P2 产出的模拟器 + 公开日志 | 不需要（但需模拟器验证） | 模拟器 + 离策略 + **模拟器验证不可省略** |
| **P5** | 公开题库 + 公开日志（真值） | 不需要（除非使用自有题库） | 多模型标注 vs IRT 真值 |
| **P4** | 本项目代码 + 外部项目 + **可选的 E4 真人实验** | E1–E3 不需要；E4 需要 | **E4 只测近端感知指标**，不测学习增益 |

**结论：五项核心工作中有四项（P1/P2/P3/P5）完全不需要自有用户，一项（P4）的 E1–E3 亦不需要；仅 E4 需要人类被试。**

### 三个必须掌握的方法学工具

1. **IRT 事前错误率**（P2 的核心）。直接用观测正确率作"错误率"会引入能力混淆的内生性。解法：在全样本上拟合 IRT（item-split 交叉拟合防泄漏），计算作答前可知的预测正确率 `p̂ᵢⱼ = σ(θᵢ − βⱼ)`，则事前错误率 `eᵢⱼ = 1 − p̂ᵢⱼ`。该量在给定 (θᵢ, βⱼ) 下与本次作答的随机扰动独立，可用于因果性的剂量—反应估计。
2. **双重稳健离策略评估（DR / AIPW）**。在无在线 A/B 的条件下，用历史日志估计反事实策略效果；只要倾向模型或结果模型之一正确，估计即一致。必须执行权重截断、报告有效样本量、设置阴性对照结局、作 E-value 敏感性分析。
3. **模拟器 + 模拟器验证**（P3 的关键，也最易受质疑）。以 P2 校准出的剂量—反应曲线 + IRT 参数 + 记忆模型构建模拟器，并以留出数据检验其预测误差（下一题正确率分布、掌握速度分布、反应时分布）。**审稿人的必杀技是"你的模拟器是循环论证"，唯一的防御是主动验证并诚实报告误差。**

> **注**：上述三条策略属于**方法学执行阶段的议题**，不属于本文档（选题与投稿组合规划）的审查范围。本文档仅确认它们构成各篇的成立前提。

## 7.4 现实性判断（个人博士项目：无经费、无大规模部署）

### 现实的（一台工作站 + 公开数据即可）

| 项 | 理由 |
|---|---|

| 让"76 个机制"的说法蒙混过关 | 审稿人查阅公开仓库即可证伪，并连带质疑全部其他数字 |
