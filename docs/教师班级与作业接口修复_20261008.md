# 教师班级与作业接口修复（第九轮，2026-10-08）

## 实际问题与变化

教师作业页面读取 classroom.classes，但后端此前不返回班级列表；仪表盘列出全部活跃学生。当前返回教师名下班级及这些班级内活跃学生，管理员可查看全部班级内学生。未分班学生不作为某教师班级数据推定归属。

布置作业、读取作业和班级热力图都检查教师所属班级，管理员保留管理权限。不存在或越权班级统一 404。知识点列表不能为空，去重后先整批验证存在性和班级年级；无效请求不创建部分作业。已有班级知识点作业更新截止日期，保持原 ID，返回 created/updated 真实计数。现有唯一约束仍保留；并发重复创建的竞争处理尚未专门验证。

热力图只汇总该班级当前活跃学生的作答，避免其他班级记录混入。该指标仍是观察作答正确率，不能解释为经过校准的掌握程度或学习效果。

## 截止时间时区修复

新截止时间必须有明确 ISO 时区，先转换为 UTC 再写入现有无时区字段；列表按 UTC 返回。10:00+09:00 的新写入返回 01:00+00:00。无时区请求返回 400，且不改变已保存日期。前端原有 toISOString() 请求兼容。旧记录如果曾以非 UTC 偏移写入，数据库已经丢失偏移，无法自动恢复原时间点；不得将其视为已完成历史校正，需作者/管理员根据原来源逐项核对。

本轮专项 tests/test_review_workflow.py 通过；此前全量 1020 成绩不覆盖本次新修改。未新增浏览器验收，完整学生作业链路仍未完成。

## 作业目录读取状态修复

TeacherPage 同时读取真实班级和知识点目录，区分加载、失败及成功空列表。失败提供重试并禁用布置按钮；未完成读取时不把目录显示为真实为空。没有班级时提示先完成班级分配，删除猜填数据库 ID 的后备入口。读取失败不静默继续布置。前端 TypeScript 与差异格式检查通过；本轮未新增浏览器验收，班级创建/分配及学生接收完成流程仍需补全。

## 班级作答统计状态

无作答的知识点返回 mastery=null、attempt_count=0，真实全错作答仍为 0%；前端不将未测量显示为能力弱。页面改称作答正确率，不称已校准掌握度。请求失败提供重试，切换班级使旧请求结果失效，避免上一班数据回写。专项数据库测试包括无作答与本班作答计数；前端 TypeScript 检查通过。未新增浏览器竞态/网络故障验收，整个作业流程仍待完整验证。

## 学生作业读取接口

新增 GET /api/v1/student/assignments，按数据库当前学生班级筛选，不接受客户端指定班级。仅活跃学生可用，未分班返回空列表。支持 limit=1..100、offset>=0，返回总数、has_more、知识点标题、截止时间和已审核可用题数；不返回答案，不把普通历史作答推定为作业已完成。

本轮数据库测试覆盖本班/他班隔离、未分班、角色拒绝和可用题数。尚未完成学生页面、作业定向选题与独立完成记录，不能宣称作业端到端链路完成。

## 学生作业信息页面

新增 /student/assignments 学生角色页面和主页入口，接本人班级作业接口，显示知识点、截止时间和审核题数。分页每页 50 条，提供失败重试，区分无作业及无可用题。数据读取采用生命周期失效检查，不在错误时伪造空列表或完成记录。页面明确目前只展示信息、不记录完成状态；定向作答与完成链路尚未补齐。TypeScript 与差异格式检查通过，本轮未新增浏览器验收。

## 作业定向题目查询

新增 GET /api/v1/student/assignments/{assignment_id}/tasks。服务器核对当前活跃学生及数据库班级关系，按作业知识点查询已审核题目，支持分页。不接受客户端指定其他知识点，不返回正确答案和解析，题目撤回审核即从结果排除。这是题目读取接口，未实现作业独立作答归属和完成记录；普通历史作答不作为作业完成证据。专项覆盖本班结果、他班拒绝、答案不泄漏与撤回审核。

## 作业题目预览界面

学生作业页面新增可展开的已审核题目预览，使用 MathContent 渲染原题公式，显示难度等级，不显示答案或解析。支持分页、错误重试、题目撤回后空结果，关闭或切换页面时旧请求失效。该界面明确不提交答案或记录完成，独立作答归属与完成链路仍需后续实现。前端 TypeScript 与差异格式检查通过；尚未新增浏览器验收。

## 作业逐题提交与持久化（最新补充）

新增 POST /api/v1/student/assignments/{assignment_id}/answer。服务器重新核对活跃学生、当前班级、作业知识点与题目审核状态，再调用统一服务器判分。新增 assignment_responses 表，保存作业、学生、题目与 Attempt 的明确关联；唯一约束限定每人每份作业每题一次提交。关联记录、判分和奖励在同一请求事务中写入，重复提交返回 409，不能再次发放奖励。读取作业题目时返回本人 submitted 标记，普通历史练习不计入该标记。

学生页面现在可输入并提交作业答案，显示服务器判分及错误答案解析，刷新后仍能读取提交状态。网络异常不伪造成功，提供原输入再次提交；服务器拦截已有记录。这里的 submitted 表示答案已记录，不表示答对或整份作业完成。

数据库部署：AssignmentResponse 定义位于已加载的 curriculum 模型模块，正常 init_db 的 metadata.create_all 会为既有数据库创建缺失的新表，不修改旧表列或回填历史作答。上线前先备份实际数据库，再由正常初始化创建该表；本轮只对临时测试数据库验证，没有操作用户数据库。尚未专门验证 PostgreSQL 部署、多个进程竞争、回滚故障注入或历史数据库升级。

当前边界：题目集合来自当前已审核知识点题库，尚未冻结成作业版本；撤回审核会改变可见题目。截止日期目前展示而不拒绝迟交。教师查看逐题提交、整份完成标准及浏览器端到端验收尚未补齐。旧段落中的“只预览”说明属于历史阶段，以本节为当前范围。

专项验证：11 passed（32.31 秒）；覆盖本班提交、他班拒绝、服务器判分、明确 Attempt 关联、重复提交不增加 Attempt、刷新查询提交状态。前端与后端全量验证结果另记，不沿用旧全量成绩。

补充数据库验证：在独立临时 SQLite 库先创建全部旧表、排除 assignment_responses，再执行 metadata.create_all；新表成功补建、旧表集合保留、作业/学生/题目联合唯一约束存在，重复初始化成功。SQLAlchemy 对既有 users/classes 循环外键发出警告，未以此认定 PostgreSQL 迁移通过。未修改实际用户数据库。

## 教师作业结果接口与界面

新增 GET /api/v1/teacher/assignments/{assignment_id}/results，仅作业所属班级教师或管理员可读。学生、其他教师不能读取。按当前班级活跃学生稳定分页，每页默认 50、最多 100；转班和停用学生不进入当前名单。只聚合 AssignmentResponse 明确关联的 Attempt，不纳入同知识点普通练习。

返回每人已记录题数、答对题数、观察作答正确率及最近提交 UTC 时间。无作答正确率为 null，真实全错为 0%，二者区分。已撤回审核题目的历史提交仍是历史记录，当前可用题目数另列，不以该数作完成率分母。题库尚未版本冻结，因此不返回“整份已完成”或学习效果结论。

教师作业台新增结果选择与分页表格，切换班级清理旧状态，请求生命周期失效检查防止旧班级结果回写，列表和结果读取失败分别提示与重试。刷新结果保持所选作业；布置成功后重读列表。作业列表请求取消缓存，避免新增作业仍显示旧列表。

数据库专项 12 passed（63.37 秒）。覆盖权限、普通练习不混入、零作答与全错区分、UTC 时间、分页、非法页长、转班后名单和题目撤回后的可用数。浏览器验收及类型检查另记。此前 1021 项全量成绩属于上一轮，不能作为本次新增接口全量通过的证据。

教师首页新增“作业布置与提交记录”按钮，避免作业台只能通过手输地址访问。结果表补列间距、按钮间距与标题层级；结果刷新与列表刷新分离，避免刷新结果时意外清空所选作业。

最终验证：12 项数据库专项通过（63.37 秒）；最终前端 TypeScript 退出 0；作业浏览器 4 项流程检查通过、page_errors 为空，包含教师首页入口、真实布置、提交网络失败不伪造成功、服务器判错、刷新后提交持久化、教师读取与结果刷新保留选择。截图已检查并改善表格列间距。git diff --check 通过。本轮未执行新的后端全量、生产构建或真实部署；不得将上一轮 1021 全量计数改写成此次新增接口的全量结果。


## 当前作业版本与整份提交标准（round23）

新增 AssignmentVersion 和 AssignmentVersionResponse 两张独立表，冻结布置时的题目内容、正确答案、解析及题目集合，并保存规范化 JSON 的 SHA-256。更新截止日期保持版本；教师显式重新布置才生成新版本，新版本不继承旧提交。学生提交携带读取到的版本，缺失或过期版本返回 409；服务器按该版本快照判分，当前撤回审核的题目不能继续提交。

整份“全部已提交”仅表示该版本全部题目已有明确关联答案，不能解释为全对、掌握或学习收益。撤回未提交题目时保持分母，显示受阻状态。教师可切换历史版本查看独立统计；历史名单仍按当前活跃班级成员查询，尚非历史名册快照。旧无版本作业保留兼容路径，不推断完成状态。

当前验证：后端全量 1023 passed、16 warnings（32.47 秒）；数据库专项 13 passed（6.12 秒）；最终 TypeScript 检查退出 0；浏览器 6 项流程检查通过，page_errors 为空，覆盖新版本清零、旧版结果查询和学生刷新新版本。独立 SQLite 旧结构升级验证保留既有 AssignmentResponse、Attempt，并可重复创建新增表；未操作用户数据库。

剩余边界：截止日期仍展示而未执行迟交策略；版本发布与提交的跨进程并发一致性、PostgreSQL 迁移及真实部署恢复尚未验收。该节取代此前阶段性“尚无版本/整份标准/教师结果”的当前状态描述；历史测试记录保留原范围。
