# K12 题库导入与复核运行说明

在项目根目录运行下列命令，使用已安装项目依赖的 Python 3.11 环境。公开题库输入为 `results/k12/xes_question_bank.json`。整理数量、格式兼容、内容审核和难度校准是不同状态；不能由导入成功推定题目正确或教学适用。

## 1. 默认预览

```sh
python scripts/k12/import_numeric_tasks.py
```

默认不连接或写入数据库。输出显示 3,209 道格式兼容题，未专家审核。题库源文件的许可与来源说明必须保留。

## 2. 在临时数据库验证命令行导入

```sh
python scripts/acceptance/verify_k12_import.py --output /tmp/learnflow-k12-acceptance
```

脚本自行创建临时 SQLite 数据库和虚构管理员，调用真实命令行导入两次，逐条比较解析、检查全部未审核和重复导入去重。数据库在结束时销毁，结果 JSON 保存在指定输出目录。该验证不审核数学正确性，也不执行难度校准或真人研究。

## 3. 指定已有本地数据库

```sh
python scripts/k12/import_numeric_tasks.py --apply --admin-id YOUR_EXISTING_ADMIN_ID --database-file /absolute/path/to/existing/local.sqlite
```

把示例管理员 ID 和路径替换为实际目标。此命令会写入明确指定的数据库，要求文件已存在且为 SQLite，并要求管理员已存在；不要把示例命令原样复制用于正式数据。默认项目连接不用于此命令。先保留目标数据库备份并关闭并发写入服务。

新题保留原解析并设为未审核。现有 ID 跳过，不自动覆盖人工修改；重复导入不会自动补写已有题目的解析。难度字段为观察成功率的粗分箱，不是 IRT 估计或完成校准。

## 4. 生成待复核材料

```sh
python scripts/k12/build_review_packet.py --output /tmp/learnflow-k12-review.json
```

脚本核对公式审计与题库哈希一致，输出 56 道被标记题的原题、原答案、解析与警告，不写数据库、不批准题目。40 题涉及公式严格模式警告，16 题涉及内容复核。其余题目未被该检查标记，不等于已审核。原图表丢失、题干/答案不一致和数学质量仍需逐题核对。

## 当前限制

该流程支持无图单数值格式。图题、选择题、多空题及非数值答案尚需适配。已导入题目必须通过实际管理员内容审核才进入普通选题；审批不自动证明难度校准。家长设置的时长上限目前仅保存，尚未由学习流程执行。完整学生作业链路与长期调度仍需验收。
