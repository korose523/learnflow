# 家长时长设置与演示权限核对（第十二轮）

实际检查发现 daily_limit_minutes 已由家长接口持久化，但学习编排器没有读取它。ParentPage 声称该设置在孩子端生效并触发休息，与实现不符。本轮改为明确提示当前尚未根据该设置限制学习时长。此项功能仍未完成，后续需要可信的服务端会话计时、各学习入口共同执行、恢复/中断与跨日处理，不能以客户端自报 time_spent 代替完整使用时长。

家长接口的演示关系推定原来不检查演示开关，也不检查家长邮箱域。现在仅显式开启 DEMO_DATA_ENABLED、非 production 环境且官方演示邮箱域时允许演示推定；其他情况下仍要求实际 parent_id 绑定。演示仍用于本地验收，不证明真实家长身份。

测试：tests/test_data_integrity_fixes.py 11 passed，2.68 秒；新增覆盖关闭演示、生产环境、合法本地演示及其他域拒绝。前端 TypeScript 结果以本轮执行输出为准。本轮未重跑完整后端或浏览器，不将上一轮全量数量写成本轮成绩。

家长上限执行、保存值缺失/加载失败显示、其他家长统计、学生作业完整链路与论文投稿材料仍需继续完善。

## 第十三轮：设置显示状态

ParentPage 现在分别保存滑块候选值与服务端已保存值。服务端 null 显示“未设置上限”，读取失败显示“尚未确认”及错误提示；40 分钟只作为可编辑候选值，不冒充已保存值。保存成功后使用响应中的实际值刷新状态，并支持发送 null 清除已保存设置。尚未读取到设置或没有设置时，清除按钮不可用。

本轮前端 TypeScript 检查通过，差异格式检查通过；未新跑浏览器，不声称家长端完整链路通过。时长实际执行、服务端计时、清除/重载浏览器验收仍待继续。

## 第十四轮：缓存孩子选择边界

打开 ParentPage 时总是获取当前家长绑定列表。只有服务器列表内的缓存孩子 ID 才能保留；无效缓存改选当前列表首项，无绑定时清除缓存和孩子状态，不因缓存跳过服务器确认。孩子列表后端只返回活跃学生角色。数据库测试验证真实绑定学生、停用学生、非学生和未绑定账号的筛选结果。
