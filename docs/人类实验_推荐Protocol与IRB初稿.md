# LearnFlow 人类实验推荐 Protocol 与 IRB 初稿

版本 recommended-draft-20261007。本文是执行前推荐方案，不是已批准、已预注册或已实施的实验。作者 wengzexiao 已确认投稿期刊未定，并要求给出招募、科目、报酬及 K12 推荐项。单位、研究负责人身份、伦理主管机构和实际预算尚未确认；不得据此启动真人招募。

## 研究目的与可证伪问题

检验目标练习正确率 85% 的一周延迟测验表现是否优于 65%、75%、95%。85% 为比较条件，无先验最优地位。所有条件使用同一界面、反馈规则、练习上限及测验流程。实际正确率与预测概率是操纵检查，后测与延迟测验独立于练习。

## 推荐招募与范围

第一阶段推荐 18 岁及以上、自愿报名的大学生或成人学习者。排除作者及指导教授正在直接授课、评分或监督的学生；不由任课教师点名招募，也不把成绩、出勤或资源获取与参加挂钩。推荐使用经机构批准的校内公共公告或成人志愿者渠道；目前未发出招募。

首轮不纳入 K12。系统演示账户的年级不能作为成年人身份依据。界面的成年勾选只是自我声明，不是年龄核验；正式方案需由伦理审批确定适当核验方式，同时尽量少收集身份资料。将来若纳入未成年人，应另写适龄材料、监护人同意及儿童同意流程，重新审批，不能直接延用本成人方案。

建议先做 12–16 名可行性预实验，检查答题负担、题库覆盖、四个目标能否实际分离、延迟返访率及记录完整性。该数字不是正式研究功效计算。正式 N 应根据预实验中的被试内变异、相关结构、最小有意义差异、三项主对比和预计失访，通过模拟功效分析确定并在招募前固定。

## 科目与题库

推荐基础数学四主题：一元一次方程、分数运算、比例应用、整数与运算顺序。成人可能出现天花板效应，因此是否采用这些主题，必须通过预实验决定。出现天花板时改换成人适宜题型，不能事后解释目标操纵失败为学习效果。

现已生成 300 道技术题库初稿，各主题 75 题，分为前测 10、练习池 45、即时后测 10、延迟测验 10。题目内容与 ID 均不跨阶段复用。答案以有理数精确生成；这是程序核对，不是专家审核。标称 Elo 难度 900–1900 只是程序演练值，未经过人类作答标定。

正式使用前至少完成独立专家核对、题意和答案审查、重复及相似题检查、难度标定和测试平行形式等值。测试题不进入实验练习，也不为这些参与者公开答案。已有应用公开题库中的相同或近似内容可能导致预先暴露；需使用独立测试题池或先核对公开内容及既往接触。

## 设计、分配与流程

每位参与者完成四个主题，各主题被分配一个目标正确率。每连续四名报名者组成一个分配块，采用带随机行序与条件序的循环拉丁方，让每人经历四条件、每主题在块内各经历一次四条件。报名后立即持久化分配，不根据结果重新分配。当前技术实现固定主题列表；正式实验还需预先平衡主题呈现顺序及时间段，记录实际顺序并检查疲劳和迁移。

每主题依次完成前测、练习、即时后测、延迟测验。练习最多 40 题或 600 秒，先达到者停止发新题；已发出的最后一题可提交，超时记录需在分析中单独说明。相同的是限制条件，并非实际练习时长必然完全相等。前测用于初始能力更新，练习中采用预先规定的 Elo 更新 K=32，后测和延迟测验不更新选题能力。此算法尚未验证为人类学习模型。

预测成功率定义为 p = 1 / (1 + 10^((题目难度−能力)/400))，选择未答练习题中预测值最接近目标的题。无合适题时仍可能达不到目标，必须记录距离及覆盖情况，不能修改实际正确率。正式上线前须先确认算法、题库标定和停止规则。

一周延迟测验不得早于对应主题后测完成后 7 天；推荐返访窗口第 7–10 天，并记录实际间隔。系统已阻止过早开始，但尚未强制第 10 天上限，分析脚本会标记晚于窗口的记录。推荐主分析保留所有有效随机分配者，缺失原因单列；预先规定窗口内分析作为敏感性分析，不以答题结果决定剔除。

## 报酬与预算建议

按访问支付固定报酬，与正确率、进步幅度及排名无关。估计首轮总负担约 80–100 分钟，延迟访问约 20–30 分钟，需用预实验实测。若研究在韩国开展，可先将主访问 15,000 韩元、延迟访问 5,000 韩元作为预算讨论起点，16 人约 320,000 韩元；此为预算建议，不是已承诺报酬、适当性结论或当地法定标准。单位、币种及预算确认后再制定真实金额和中途退出的按已完成负担支付规则。退出不能要求退还已获得报酬。

## 主要结果与分析

主要结果为延迟测验逐题正误，前测作为基线；即时后测为次要结果。推荐混合效应二项模型，固定效应包括条件、前测成绩、主题与呈现顺序，被试和题目作为随机截距。只有四个主题时，主题优先作为固定效应而非据少量水平估计随机方差。若模型不收敛，备用分析及报告方式须预注册；不得在结果出现后选择最有利方法。

三项主要对比为 85% 对 65%、75%、95%，使用 Holm 调整，报告效应及区间，禁止只报告显著比较。首先报告实际练习正确率、预测概率、距目标差、题池覆盖及停止原因。操纵区分不足时结论限于可行性，不能检验“85% 最优”。目前配套汇总脚本只生成记录质量与描述统计，不进行确认性检验；功效模拟与混合模型需在最终设计确认后编写。

## 同意与数据管理草案

正式同意书应使用参加者熟悉的语言，说明目的、任务和时长、自愿性、可随时退出、报酬、数据类型、存储位置、保存年限、退出后删除或排除的截止点、匿名汇总后无法追溯删除的界限、研究负责人和伦理机构联系方式。实际机构与联系方式未提供，不能发送本草案给真人签署。

研究记录含随机研究 ID、阶段、主题、分配目标、题目 ID、首答、判分、客户端反应时、服务器时间、预测概率、题目与能力参数、同意版本及时间。导出没有姓名、邮箱、应用 user_id、家长 ID 或 IP，但研究 ID 与账户映射在数据库中存在，因此是去标识化记录，不应声称不可逆匿名。联系人/支付台账应另存并限制访问；目前没有自动生成此类台账。

默认导出排除撤回者。数据库仍保留其原始记录供审计；这不等于实现永久删除。正式研究须确定适当保存年限、备份权限、删除流程及合法保留依据，并在同意书中真实说明。数学首答限制为数值、分数或单变量等式，减少误填个人文本。

## 实验装置与实施边界

独立地址 `/research/:studyId` 只显示研究说明、阶段、题目、答案与标准反馈，不调用宠物、积分、排行榜、健康分、风险标签或生成式辅导。各条件的目标值不显示给参与者。管理员研究导出与家长学习摘要分开。

研究题库在开放后冻结；同意、分配、会话和题次持久化。正式模式开放需管理员记录真实批准依据、至少 300 道专家审核且具有校准来源的题，以及可用的指定数据库。后台文字确认不能自动核实伦理文件真伪，责任仍在研究负责人。服务器的检查也不是伦理审批。

技术演练已用临时数据库测试，不是作者亲自体验。教授要求的“本人从头到尾作为被试跑一次”仍需 wengzexiao 在演练模式亲自完成并对照导出。正式招募前还需确认主题顺序、数据隔离、访问负担、研究角色和退出政策。
