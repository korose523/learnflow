# K12 题目显示与界面证据核对

2026-10-08，续第四轮项目修复。当前论文仍以公开二次数据、离线评价和模拟推进，不开展新真人实验。本轮工作改善题目显示与反馈表述，不新增学习效果证据，不追溯修改已封存论文包。

## 数学显示

新增共享 MathContent 组件用于 `/learn`、`/student/learn`、教师题目预览、管理员题干/答案/解析审核和学生讲解。纯文本及换行保留；定界公式使用固定版本 KaTeX 0.19.0 和本地打包字体。XES 用 `$$...$$` 标记题干内的数值，因此美元定界公式按行内处理，`\[...\]` 显示为独立行。无法解析的表达式保留完整原文，不让一个公式破坏整页题目。

原文由 React 作为文本显示，只有 KaTeX 产生的标记进入 HTML。外部内容命令关闭，公式不共享宏，设置尺寸及展开次数边界。依赖版本写入项目锁文件，许可随前端 public/third-party 保存；这没有为 LearnFlow 自身指定新发布许可证。配置依据 [KaTeX API](https://katex.org/docs/api.html) 和 [options](https://katex.org/docs/options.html)。

## 全题库语法核验的范围

`audit_math_render.cjs` 对现有数值格式子集 3209 题执行原文保留和公式语法排版检查。10395 段公式均无解析异常；176 条严格模式提示分布在 40 题中。另有 16 题包含表格/图示措辞，需要核对原始数据是否已丢失结构。这些项目没有被自动删除、改写答案或标成专家审核通过。

JSON 输出至 `results/k12/math_render_audit_20261008.json`，保存题库、分词器、组件、锁文件哈希与逐项提示。检查只证明当前定界公式的语法可解析；不证明公式含义、答案正确、排版逐题优良、表格重建、图题/选择/多空适配、专家校准或 IRT 难度。

公开题库的部分表格已经在原始元数据中压平为连续文本，简单数学排版不能恢复它们。完整题干核验和其他题型适配仍是项目未完成项；不能将 3209 题写成全部内容已经可直接教学使用。

## 反馈证据边界

一次正确作答不能证明技能掌握、个人记忆改善或具体脑部变化。本轮将庆祝文字改为“回答正确，继续练习巩固”，并改写后端正误反馈中的个人神经变化判断。检索练习提示改成独立回顾与核对步骤，撤去“一次测试相当于重新学习四次”的未限定固定倍率。

这不是全部学习方法说明的文献复核。其余页面中的健康、风险、AI 数值与学习方法科学解释仍需要逐项检查，不能据本轮文字修正宣布全部主张已经验证。

## 运行验收

在独立新建 SQLite 数据库、虚构演示账号上延续第四轮真实 UI/API 链路，增加教师预览、两个普通学习入口的分数结构检查，以及 390px 视口的横向溢出检查。出题、审核、主题选择和判分仍由实际服务器执行，只将下一题主题限定到虚构题目。验收结果以本轮保存的 JSON、截图和退出状态为证据，不把断网注入当作真实用户数据。

本轮没有修改判分算法与研究结果。第四轮后端全量 1006 passed 是历史运行证据；本轮单独运行学习方法与服务回归，并进行前端 TypeScript 和生产构建。不得把历史全量测试写成本轮重新执行的全量测试。

完整目标继续保持未完成：剩余题型、题干质量、教师作业/学生复习/家长限制链路、独立种子命令与部署验收，以及论文外部证据和最终投稿信息均须继续推进。

### 难度数值显示纠正

截图核对发现 `/learn` 把题目等级 5 当作 5% 放入固定 75–85% 的心流通道。当前接口没有给出此处需要的预测正确率，二者不能混用。现在以“题目难度等级 5/10”显示实际题目字段，并撤去主学习页的固定正确率通道。本轮还移除随机反馈中未计算的“掌握度 +1”“超越昨天”和“能力曲线稳步上升”判断。其他页面的尺度与默认值仍待逐项核对。
