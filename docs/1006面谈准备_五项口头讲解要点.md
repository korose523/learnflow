## 2. 五项口头讲解要点

### 要点 ① π_k（有效权重）的推导

**出处**：M1 完整稿 §3.2（L135–137、L154）、§4.2（L179–187、L226）；报告 L131。

- 融合规则：`S = Σ_k w_k · z_k`（`z_k` = 第 k 源映射值，`w_k` = **名义**权重）。
- 以**边际贡献**定义有效权重：**`π_k = w_k · Cov(z_k, S) / Var(S)`**，且 `Σ_k π_k = 1`。

**为什么 Σπ_k = 1（黑板推导要点）**：
`Σ_k π_k = Σ_k w_k·Cov(z_k,S)/Var(S) = Cov(Σ_k w_k z_k, S)/Var(S) = Cov(S,S)/Var(S) = 1`。

**命题 C1（不稳定性）**：各源先归一化到 [0,1] 再线性加权 → `π` 一般 ≠ `w`，且随任一源的**单调重参数化**漂移；各源先经**经验 CDF → logit** 公制再融合 → `π` 对任意严格单调重参数化**严格不变**。

**实测（要能背出）**：
- 合成基准：`π⁽⁰⁾ = [0.5429, 0.1514, 0.1831, 0.1226]`；掌握度源名义 0.40 → 有效 **0.532**（离散度大被放大），记忆难度源名义 0.30 → 实际 **0.171**。
- 分位 logit 公制下有效权重回到名义值附近，**最大偏差 0.003**。
- assist09 三源：`π = [0.9371, 0.0745, −0.0106]`（含负值）。

**必被追问：π 取负值怎么读？**（§3.2 已显式定义，M1 L816）
→ 答：**负 π 是「反向抵消」，不是「负份额」**；源间协方差为负时出现（assist09 三源两两负相关 −0.25/−0.13/−0.30）。**L1 漂移把负分量计入是刻意保守**（若只计正分量会低估漂移）。

**诚实边界**：「分位公制下有效权重不变」一侧是**解析恒等式**（`#{g(x_cal) ≤ g(x)} = #{x_cal ≤ x}`），本文贡献是**量化该恒等式被违反时差异有多大**，不是「证明了命题」（M1 L150、L818；审阅 §3.4）。

### 要点 ② λ_cf 的拟合过程

**出处**：M1 §7.5–7.7（L472、L488、L524）；`_重写规范_事实基线与学术体例.md` L55；M3 L207、L410。

- 闭式：**`λ_cf(k) = 1 / (1 + (k / 27.3)^0.895)`**（Hill 型收缩）。
- 拟合参数：**留一 k 交叉验证** `k₀ = 27.332、p = 0.895`；**全量拟合** `27.4 / 0.902` → 两者几乎一致，**曲线形状稳定**。
- 取值（要能背出）：`k = 10/25/50/100/200 → λ = 0.711/0.520/0.368/0.238/0.144`。
- 区间内插检验：**公式区内插的 λ̂ 略优于折半挑出的经验 λ\***（保留比例 **111% 与 128%**）→ 原因：经验 λ\* 自身带**选择噪声**。
- 结论：**λ\*(k) 无需按部署重新调参即可直接使用**。

**诚实边界（必被追问）**：λ 收缩**只在 Junyi 上验证**，**DBE 上无收益**，未跨系统复现（M1 L700、L720）。

### 要点 ③ srw7 的定义

**出处**：M1 §7.8（L514–L523、L554–L556）。

变体谱系（要能说清差别）：

| 变体 | 定义 |
|---|---|
| `fused6` | O8「剔除升级率」的 6 信号**等权** |
| `fused7` | O5 的 7 信号**等权** |
| `signed7` | 7 信号等权 + 按拟合段内秩相关**校正每信号符号**（`success` 符号固定 +1） |
| `rw6` | 6 信号按**折半信度**加权 |
| **`srw7`** | **7 信号同时做符号校正 + 折半信度加权** |

**权重**：`w_s = max(0, 折半信度_s)` 归一；折半信度**在拟合块 A 内估计**（对半切分后两半段估计之间的秩相关）——**不接触判据块 B**。信号集为全部 7 个信号（含**升级率，被符号校正为负贡献**）。

**实测（要能背出）**：
- `signed7 > fused6` 在 k = 10/25/50/100/200 **逐档成立**（k=10：+3.594 对 +3.278 pp；k=200：+0.111 对 +0.071 pp）→ 说明「剔除」丢弃了信息，错误在**方向**不在信息量。
- `srw7` 在**全部 k 上最优**：记录级 **+3.823 / +2.025 / +0.930 / +0.391 / +0.138 pp**；学生级 k=100 为 +0.335 pp、k=200 为 +0.102 pp。

**诚实边界**：O11/O12 优化**只在 Junyi 上验证过**，未跨系统复现（M1 L700）。

### 要点 ④ 七元组的理论出处

**出处**：M2 完整稿 §3.1（L142–L156、L239）；`LearnFlow_期刊论文拆分方案.md` L456。

**定义**：`Intervention = ⟨trigger, target_construct, direction, channel, cost, side_effect, precedence⟩`
`trigger` 触发条件；`target_construct` 作用构念（参与度/坚持性/自我效能/社交联结/时长）；`direction` 促进/抑制（**冲突检测关键字段**）；`channel` 呈现通道；`cost` 预算消耗；`side_effect` 已知副作用；`precedence` 合规优先级。

**审计实测（要能背出）**：
- `trigger`（实现为 `stage`）**54/54 可得**；`direction` **12/54 可得**；
- `target_construct`、`channel`、`side_effect`、`precedence` **在代码中根本不存在**（注册表与编排器均未定义，只能由分析者从文档语义反推）。
- → 不可归类 **42/54 = 77.8%**，触发自设 > 20% 阈值。

**定性（关键，别夸大）**：该结果是**「schema 粒度与实现粒度不匹配」**，是**实现完成度的诊断（设计者自审）**，**不是关于外部世界的发现**（M2 L239）。

**类型 I · 语义对消**：`target_construct` 相同但 `direction` 相反且触发窗口重叠。本项目实例：错失恐惧提示（目标=时长，方向=促进）vs 未成年保护（目标=时长，方向=抑制，合规强制）vs 休息提醒（目标=时长，方向=抑制）。

### 要点 ⑤ Bradley-Terry 的聚合方式

**出处**：M3 完整稿（L229、L364–L365）；审阅 §5.2 与配对 bootstrap 结论。

**E1-B 流程（要能讲清）**：
1. 要求模型输出**枚举数组** `{"ranking": ["A","B","D","C"]}`；
2. 共 **60 批**，解析失败 **13/60（21.67%）**，得 **697 个两两约束**（该形态单独 `ρ = 0.1553, p = 0.024`）；
3. 两种形态合并后为 **108 批、1,362 个两两约束**；
4. 再以 **Bradley-Terry 模型聚合为强度值** → 最终 **`ρ = 0.1808 (p = 0.0083)`**，为**可引用**结果。

**对比 E1-A**：绝对（锚定）评级 `ρ = 0.2195`。两者差异经**配对 bootstrap（题目级 + BT 重拟合）**：`Δ = 0.0385，95% CI [−0.0652, 0.2193]，p = 0.34` → **不显著**。

**必须主动划清的两条失败实现（不得当证据）**：
- v1（`num_predict = 16` 截断思考，标签从思考文本读出）→ `0.0295`；
- E1-B 首轮自由字符串排序（108 批中 60 批解析失败 / `ρ = 0.0478, p = 0.489, n.s.`）。
→ 这两者是**失败的协议实现（工程压力测试）**，已移「工程教训」一节；「四种答案」的说法**已删除**。

**诚实边界**：「协议稳健性 > 方法选择」的方法论主张，**只有两个有效协议比较**（0.2195 对 0.1808）且差异不显著；主张须**收窄**，不能把失败运行当样本。
