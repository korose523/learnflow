**裁定时须一并回答的子问题**：
- 若选「正式卷期年」：参考文献表里的**卷/期/页**不变，只改年份，读者按卷期仍可定位——代价是与 DOI 年份段不一致。
- 若选「在线发布年」：与 DOI、与多数引文管理软件的自动抓取一致——代价是同一卷次内可能出现"2024 年的文章落在 2025 卷"。
- **同一库内必须唯一**：现在 bib 里 `Sensors`（Rosas）与 `Multimedia Tools Appl`（Choudhary）两处已按**正式卷期年**著录（2026 / 2025），若本表改选在线发布年，那两处也要一起回退。
